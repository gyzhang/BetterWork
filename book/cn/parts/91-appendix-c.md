### C.1.1 引用一条数字时必须带的三样

任何写进本书的时效性数字，都必须能回答三个问题：

```text
① 谁发布的（发布方 / 评测执行方）
② 什么时候（发布日期或测量时间窗口）
③ 怎么算的（样本、口径、是否 pass^k、有无预算限制）
```

**答不齐三样的数字，本书不写。**这条纪律与第 0 章"数据三问"、第 13 章"基准读法"是同一条。

## C.5 引用规范：怎么写才可核查

本书对引用格式的要求，来源于一个很实际的问题：**引用是给别人去核的，不是给自己加分的。**

| 要素 | 必须写吗 | 例子 |
|---|---|---|
| **可定位** | 是 | 版本号、章节号、编号，而不是"官网" |
| **发布日期 / 测量时间窗口** | 时效事实必须 | "2026-07-28"而不是"最近" |
| **访问日期** | 动态页面必须 | "2026-09-18 访问" |
| **口径** | 数字必须 | "通过率 79.2%，pass@1，官方榜" |
| **局限** | 有争议或易误读时 | "厂商自述，未独立复现" |

**一条负向规则**：**不要写"据研究"、"有数据显示"、"业内普遍认为"。**这三个短语的共同问题是——**它们把核查成本全部推给了读者，而读者没有能力承担。**

如果你不知道数字的来源，那个数字就不该被写进来。**删掉一个说不清的数字，比留下一个说不清的数字更专业。**这条从第 0 章贯穿到这里的纪律，在引用规范上有了它的最终形态。
