# ppt-generation-expert wheelhouse

这是 `ppt-generation-expert-darwin-arm64-cp312.json` 对应的离线 wheelhouse。文件名、版本、SHA-256 和许可字段与 [依赖锁](../dependency-locks/ppt-generation-expert-darwin-arm64-cp312.json) 一一对应；`manifest.json` 是随包分发的许可与大小清单。

这些 wheel 只用于 macOS arm64 / CPython 3.12 的受管环境。运行时使用 `pip --no-index --require-hashes`，缺文件、hash 不符或 import 探测失败都会拒绝把环境标为 ready。上游包的完整许可文本随 wheel 的 `.dist-info` 元数据提供；本清单保留锁文件中的许可标识，便于发布前核对。
