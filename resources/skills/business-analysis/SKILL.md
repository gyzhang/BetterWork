# 经营分析方法

先确认当前期间、对比期间、预算口径和单位。只从本次 Run 已选择并实际读取的材料提取数值。

对每项指标调用 `analyze_business_metrics`，把当前值放入 `current`，对比值放入 `previous`，预算值放入 `budget`。不要在提示词中自行心算或补齐缺失值。

输出时保留原始数值、变化额、变化率和预算偏差；遇到零基数、缺失期间、单位不一致或异常值，明确标记并请求用户确认。
