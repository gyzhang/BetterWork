# 公司模板档案：中电金信

> 本档案是中电金信模板的**唯一事实源**（色板/字体/字号/版式/坐标），写任何页面前必读。规范 2026-09 从《中电金信模板.pptx》第 3 页"配色及辅助图形说明"提取。模板文件：本 skill `assets/中电金信模板.pptx`。

## 1. 基础

- 画布 1280×720 px（13.33×7.5 英寸 16:9，96dpi，坐标体系通用）
- svg_native_export.py 缺省 spec_lock 即按本模板默认值生成（主蓝 #1B4593 / 藏蓝 #0C2864 / 微软雅黑）

## 2. 色板（模板第 3 页：使用频次从左到右递减）

主色（高频 → 低频）：

| 色值 | 名称 | 用途建议 |
|---|---|---|
| `#1B4593` | 主蓝 | 竖条、主色块、强调文字、图表主色 |
| `#778495` | 灰蓝 | 辅助文字、次级图元 |
| `#E4E6EA` | 浅灰 | 卡片底、分隔、浅底面板 |

辅助色（点缀，低频使用）：

| 色值 | 名称 | 用途建议 |
|---|---|---|
| `#266DE7` | 亮蓝 | 渐进/次强调、图表第二序列 |
| `#00D3E4` | 青 | 高亮点缀、数据可视化辅助 |
| `#048AE3` | 青蓝 | 图表第三序列 |

深色与强调：

| 色值 | 名称 | 用途建议 |
|---|---|---|
| `#0C2864` | 藏蓝 | 深色底栏、页标题文字 |
| `#DF203C` | 红 | 仅作警示/风险强调，单页少量使用 |

配色纪律：主蓝 #1B4593 承担最大面积；藏蓝 #0C2864 用于标题与深底；白底占比 ≥60%；红色克制；**禁止引入色板外颜色**；语义色在色板内解决——红 #DF203C 表风险/负值，青 #00D3E4 或亮蓝 #266DE7 表正向。

### 2.1 主题槽位真实值 与 spec_lock colors 标准块（防串色，必读）

导出器会把 spec_lock 颜色写成 schemeClr 主题引用，**合并进公司模板后按模板主题解析**。角色→槽位规则：`bg→lt1`、`primary→accent1`、`accent→accent2`、`secondary_accent→accent3`、`border→accent4`、`text→dk1`、`text_secondary→dk2`；**其余角色按声明顺序前 2 个依次占 accent5/accent6**；未占槽的颜色保留显式 srgbClr（永远安全）。

模板主题真实值：`dk1=000000` `lt1=FFFFFF` `dk2=778495` `lt2=F0F0F0` `accent1=1B4593` `accent2=266DE7` `accent3=048AE3` `accent4=00D3E4` `accent5=0C2864` `accent6=DF203C`。

spec_lock.md `## colors` **标准块（直接拷贝，勿改角色名/顺序）**：

```
## colors
- bg: #FFFFFF
- primary: #1B4593
- accent: #266DE7
- secondary_accent: #048AE3
- border: #00D3E4
- text_secondary: #778495
- navy: #0C2864        # extra#1 → accent5（与模板一致）
- risk: #DF203C        # extra#2 → accent6（与模板一致）
- panel: #E4E6EA       # 第 3 位落选 → 显式 RGB（安全）
```

红线：**禁止**用 `text:` 角色锁深色（dk1 恒黑，深藏青会被渲染成纯黑）；**禁止**把浅灰/非主题色（如 panel）声明在 extra 前 2 位（会被塞进 accent5/6 槽——2026-09-08 事故：浅灰面板被解析成红 #DF203C、深藏青被解析成黑，整册视觉灾难）。自定义角色名可换，但 navy/risk 两个槽位色的角色**必须**排在 extra 前 2 位且值与模板一致。

### 2.2 效果使用边界（渐变 / 阴影 / 光晕）——2026-09-16 Kevin 定调

**总原则：绝对禁止黑色大块与大面积红。若使用渐变/阴影/光晕，一律不得使用黑或红——它们与蓝色科技系主题冲突。**

| 效果 | 允许 | 禁止 |
|---|---|---|
| 阴影 | `#1B4593` @ 8~12% 或 `#0C2864` @ 8~10% 低透明度；偏移 ≤4px、模糊 ≤12px | **纯黑阴影**（含任何深到接近黑的色值）；红色阴影；多层阴影堆叠 |
| 渐变 | 同色系深浅：`#0C2864 → #1B4593 → #266DE7`；中性：`#FFFFFF → #E4E6EA` | 黑色作为渐变端点；红色参与渐变；跨度跳出色板的彩虹渐变 |
| 光晕 | 仅高亮数据点/关键节点；`#266DE7` 或 `#00D3E4`，透明度 ≤25% | 整卡/整块的弥散光晕；`#DF203C` 光晕；光晕面积超过单页 10% |

附加约束：
- 同一图元的效果叠加 **≤2 种**（例如"渐变底 + 阴影"可以，"渐变+阴影+光晕"不行）
- 效果**不得改变信息编码**——条长、点位、角度、面积一律不受效果影响
- 红色 `#DF203C` 的既有约束不变：仅小字强调/细边框/小红标，单页 ≤5% 版面，且**不得进入任何渐变、阴影或光晕**
- 内容页仍一律白底；深藏青 `#0C2864` 仍仅用于标题条/结论条/阶段块
- 效果是**层级与质感提示**，不是装饰配额：删掉效果页面依然成立，才是用对了

## 3. 字体

- 中文：Microsoft YaHei（标题/正文）、Microsoft YaHei Light（大段说明/辅助文字）
- 西文/数字：Arial 或 Calibri
- 全部为导出器 PPT-safe 字体；思源宋体/宋体等 serif 字体不使用

## 4. 字号体系（模板母版与版式标注）

| 层级 | pt | px（96dpi ≈ pt×4/3） | 用途 |
|---|---|---|---|
| 页标题（母版标题档） | 44 | ≈59 | 封面/章节页大标题（版式承载） |
| 页标题（内容页紧凑档） | 28 | ≈37 | 信息图解内容页标题（版式承载） |
| 区块标题 | 24 | 32 | 卡片区/分组标题 |
| 一级正文 | 20 | ≈27 | 重点结论、大数字说明 |
| 二级正文 | 18 | 24 | 卡片标题 |
| 三级正文 | 16 | ≈21 | 卡片正文 |
| 辅助注释 | 12 | 16 | 页码、脚注、来源 |

实操口径：内容密集图解页，卡片标题 20~21px；卡片正文 14~16px；辅助注释 ≥13px。宁大勿小，避免 11~12px 小字。未声明字号（体系外字号如 26px）一页 ≤2 次，否则用 22px（质检规则）。

## 5. 版式与标题职责

- **可用版式**：封面、封底、章节页、标题_内容_底纹、标题_底纹、空白_底纹、标题_内容、标题、仅空白、无logo全空白
- **用户偏好**：内容页默认「标题」版式；「标题_底纹」仅用户点名时用（两者占位符几何一致）
- **标题职责**：页标题一律由版式 title 占位符承载（merge 时经 pages.json 的 `title`/`tag`/`subtitle` 写入），SVG 内任何情况下不画标题；版式标题档位内容页 28pt、封面/章节页 44pt，由母版决定，AI 不干预

## 6. 布局坐标（由本模板"标题"版式占位符几何决定）

- 标题占位符区 **y 58~114 禁入**（任何元素不得绘制）
- 内容区 **y 135~690**（推荐 148 起）；安全边距 **x 70~1210**
- 底注/来源行 y ≤ 690；页脚、页码由模板母版负责，SVG 不绘制

## 7. 辅助图形语言（模板第 3 页"建议的辅助图形"）

- 推荐形状：**平行四边形、直角三角形、菱形、圆角矩形**（斜切几何风）；流程箭头可用三角形
- 圆角矩形（rx 8~12）作卡片与节点底板，与模板卡片语言一致
- 白卡（rx12）顶部彩色头带 path 写法见 references/workflows/delivery.md「铁律 5」

## 8. 图表配色序列

- 类别/序列色：`#0C2864 → #1B4593 → #266DE7 → #048AE3 → #00D3E4`
- 风险/负值 #DF203C；正向语义 #00D3E4 / #266DE7；禁止色板外颜色

## 9. 总起页深色侧栏

深色侧栏用 `#0C2864`；金色点缀改用 `#00D3E4`（青）或保留少量 `#DF203C`，不引入色板外颜色。
