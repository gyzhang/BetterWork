# duty-manual（职责／制度手册）风格包

> 上游方法原文：`$PPTM_HOME/skills/ppt-master/templates/styles/duty-manual/templates/design_spec.md`
> 本包 = 上游方法内核 + **中电金信模板落地裁决** + 页序模板 + 交付前自查。**模板档案优先于上游默认。**

## 1. 何时用 / 何时不用

| | 场景 |
|---|---|
| **用** | 管理办法／操作规程宣贯、岗位职责说明、技术标准与培训课件、内部技术分享——**规则散落在多份文档、要收拢到一条可判断的轴上** |
| **不用** | 经营通报（→ `operating-review`）· 对外方案（→ `mbb-consulting`）· 争取资源（→ `investor-pitch`） |

**判据**：如果受众需要**当场依据它做判断**（而不是事后背条款），用本风格。它的核心目标是"标题写成可判断的句子、机制先于规则、每条规则可回溯到机制页、读者始终知道自己在轴上哪一档"。

## 2. 方法内核（4 条不可妥协）

1. **标题写成可判断的句子**，不写名词短语——`"进入水域是最后手段"`，不是 `"水域救援"`。
2. **机制先于规则**：规则**不得**以孤立条款出现，承载它的机制页必须在前；引用规则时要标出它回溯到哪一页机制。
3. **全册一条判断轴贯穿**：任何一页都能回答"我们当前在哪一档、哪一步"。
4. **外部事实必须标来源与年份**；为本材料自建的框架／分级要标明"自建"而非"引用"；**冲突的表述并列呈现并说明取舍依据，不得静默消解。**

## 3. 页序模板（按章节组织）

| # | 页面角色 | 页面职责 | 建议图形域 | 页数 |
|---|---|---|---|---|
| 1 | 影响开场 | 用规模事实建立"为什么值得重讲"（每个数字带来源与年份） | 大字号数字块 + 底部颠覆性结论 | 1 |
| 2 | 章节页 | 标出本章开始与它要回答什么 | 满版（**仍是白底**，靠超大章节号 + 判断句建立视觉主体，非深色） | n |
| 3 | **机制页** | 讲透一个机制，使后续规则可被推导 | `diagram/flow_chart`　`diagram/network_graph`（图近半页） | n |
| 4 | 轴总览 | 全册的判断顺序一屏看全（每档定义 + 随档升高的两项代价） | `diagram/timeline_chart`　`chart/stacked_bar_chart` | 1 |
| 5 | 分档页 | 讲一档的定义、代价、升级触发条件 | 图 + 关键点分栏 + 左上角档位牌 | n |
| 6 | 技法页 | 展开一个具体做法并标出它属于轴的哪一档 | `diagram/flow_chart` | n |
| 7 | 清单表页 | 让读者逐条核对（每条写它挡住什么风险） | `table/record_table`　`table/feature_matrix` | n |
| 8 | 编制／责任表页 | 岗位、编制数、职责（阈值写清成立条件） | `table/metric_table` + 编制徽标 | n |
| 9 | 流程序列页 | 给出不可调换的步骤顺序 | `diagram/flow_chart`　`diagram/project_schedule_table` | n |
| 10 | **反例页** | 点名一个离开轴的做法并剖析它为何失效（≥2 个机制 + 1 次回顾前文数据 + 替代做法） | 主图 + 禁止标记 | n |
| 11 | 收口标准页 | 把规则折回已教的机制（每条标出回溯页） | 密集多栏 | 1 |

**阅读节奏**：图文在相邻页左右互换；每章至少留一个**明显低密度页**作喘息。**密度跟随信息权重，绝不用条目填满页面。**

## 4. 标题写法（可判断的句子）

| ✅ 可判断 | ❌ 名词短语 |
|---|---|
| 进入水域是最后手段 | 水域救援 |
| 单点估算不可作为预算依据 | 估算方法说明 |
| 阈值一旦触发，升级不由现场决定 | 升级流程 |

## 5. 数据与证据表达

- **绝不同轴混放量级悬殊的序列**：把特大的那个单列成数值块并写明倍数（如"是其余各项之和的 3.2 倍"），让图表保持可读。
- 数据点必须**按刻度精确计算，不得目测**。
- **非线性关系的结论直接写进标题**——"翻倍，则四倍"。
- **表格**：横向行线而非全网格；表头靠填充 + 加粗区分；**关键行用文字颜色强调而不是填充**（填充会与表头混淆）；数字右对齐、单位一致。
- **页脚给来源名与参考年份**；同一指标有多种定义时并列列出并说明本页用哪个；**找不到出处但广为流传的数字直接不用**，并注明为什么不用。

## 6. 中电金信落地（这是一次"方法照搬、视觉重做"的改造）

**上游的暗底场必须改掉**——与铁律 10「内容页一律白底」冲突。改造映射：

| 上游默认 | 本管线裁决 |
|---|---|
| 整册暗底 `#0E1B2E` + 面板 `#1A2C46` | **全部改白底**：页面 `#FFFFFF`，面板 `#E4E6EA` |
| 结构线／次级标题 `#4A9FD8` | **`#778495`** 灰蓝；主结构线用 `#1B4593` |
| accent 荧光黄 `#D8F04A`（关键量／正确做法） | **`#266DE7` 亮蓝**；关键量另加**加粗 + 大字号**补足"醒目" |
| secondary_accent 橙 `#E85D2B`（危险／禁止／最高风险） | **`#DF203C` 红**（仅小字／细边框／小红标；大面积红被禁） |
| 正文 `#DCE6F0` / 弱化 `#8FA3BC` | **`#0C2864`** / **`#778495`** |
| 分隔线 `#2A3F5C` | **`#E4E6EA`** |
| 容器：发丝描边方框、圆角 0、无阴影 | **保留"方角"以体现手册性格**：本风格页的容器用 `rx=0` 细线方框，与圆角卡片区分。装饰条用 `scripts/round_accent_strips.py` 时宿主 `rx=0` 不参与 L5 校验 |

**保留上游最有价值的两个视觉装置**（改白底后可照用）：

1. **左边缘章节进度指示条**——固定在第 1 列（x=70），当前章节用强调色点亮，离开轴的内容整条转为警示红。这是"读者始终知道自己在轴上哪一位"的落地形式。
2. **细线网格 + 引出线标注**——网格与引出线本身就是信息载体（不是装饰）。

**字号**：只用 spec_lock `## typography` **声明的角色值**（模板：`tests/fixtures/spec_lock.full.md`）：13（辅助注释，下限）/ 14（正文）/ 16（节点与小标题）/ 21（强调）/ 22（大数字）/ 24（卡片标题）。**下限 13px，禁止 11~12px**（口径与 `operating-review` §6 同源，仲裁规则见 `doc-writing-discipline.md §4`）。上游 `display` 用 Arial Black 做大数字，本管线用**微软雅黑加粗 + 大字号（22）**替代。

**表格原生化提示**（上游明确要求）：清单表／编制表／对比矩阵这类**下游会编辑的表优先用原生可编辑表格**（见 references/workflows/delivery.md §4.5 与 `native_table_inject.py`）。上游另有一条坑值得记住：**暗底上的原生表格必须显式声明单元格填充**，否则会导出成"白底浅字"——本管线改白底后此坑消失，但若将来做深色章节页要重新注意。

## 7. 与铁律／模板档案的冲突裁决（汇总）

| 上游默认 | 本管线裁决 |
|---|---|
| 暗底满册 | **白底**（铁律 10） |
| 荧光强调色 | 主题蓝族 + 红；靠粗体与大字号补醒目度 |
| 方角容器、无圆角 | **保留方角**（rx=0），作为本风格的识别特征 |
| 页码/来源在页脚 | 保留；来源行格式对齐档案 §6 的页脚规范（底注/来源行 y ≤ 690；页脚、页码由模板母版负责，SVG 不绘制） |

## 8. 真实范例

本风格暂无整册交付范例。**最接近的现成素材是本 skill 的 8 个关系／结构图骨架**（`assets/diagrams/`），它们的形态与本风格的机制页／序列页一致：

| 骨架 | 对应本风格的页面角色 |
|---|---|
| `diagram/flow_chart` | 机制页、流程序列页（含判定菱形与条件分支） |
| `diagram/org_chart` | 编制／责任表页（层级归属） |
| `diagram/milestone_chart` | 分档页（阶段带 + 验收点） |
| `diagram/project_schedule_table` | 清单表页／排期页 |

先看 `assets/atlas/diagrams-01.png`、`diagrams-02.png` 确认形态，再按本包规则改造成本节的具体内容。

## 9. 交付前自查（6 条）

- [ ] 每页标题是可判断的句子，不是名词短语
- [ ] 每条规则都能回溯到某页机制，且引用处标了回溯页
- [ ] 左边缘进度指示条的当前位置与页面内容一致；离开轴的内容已转警示色
- [ ] 两个强调色分工未互换、未混用同一含义
- [ ] 量级悬殊的数据没有被强行放在同一坐标轴上
- [ ] 外部事实都带来源与年份；自建框架已标明"自建"
