# mbb-consulting（顶级咨询式论证）风格包

> 上游方法原文：`$PPTM_HOME/skills/ppt-master/templates/styles/mbb-consulting/templates/design_spec.md`
> 本包 = 上游方法内核 + **中电金信模板落地裁决** + 页序模板 + 交付前自查。**模板档案优先于上游默认。**

## 1. 何时用 / 何时不用

| | 场景 |
|---|---|
| **用** | 对外方案／投标、给领导的管理决策文件、议题请示、需要"桌面阅读距离"高密度论证的文档 |
| **不用** | 定期经营通报（→ `operating-review`，本风格过密）· 宣讲／主旨演讲（密度过高，投影场景不可读） |

**判据**：受众会**拿着文件逐条审阅并追问出处**时用它；受众是"坐着听你讲"时不要用。

## 2. 方法内核（4 条不可妥协）

1. **金字塔贯穿全册**：`总答案 → 关键支撑 → 页消息 → 证据`，每一页必须可回溯到某个支撑论点。
2. **每页一条动作标题（action title）**：标题就是该页的答案，不是话题。**支撑证据必须放在答案的正下方或紧邻处。**
3. **主张四分法**：事实／假设／推论／建议语义分离——事实给出处、假设标不确定性、推论从可见证据推导、建议配理由与行动。**绝不把无支撑的主张升格为结论。**
4. **缺口可见**：证据缺失或假设未决时**明写**，不用自信的措辞把缺口盖过去。

## 3. 页序模板（决策文件基准）

| # | 页面角色 | 页面职责 | 建议图形域 | 页数 |
|---|---|---|---|---|
| 1 | 封面 | 唯一允许的深色满版页 | 纯版式 | 1 |
| 2 | **执行综合** | 统领性决策 + 总答案 + 支撑要点（带页码索引） | `table/metric_table` + 推论面板 | 1 |
| 3–4 | 现状与矛盾（SCQ） | 建立情境、暴露张力、给出化解方向 | `chart/line_chart` + 关键信息栏 | 1–2 |
| 5 | 驱动分解 | 决定结果的关系是什么（分支要各自有支撑） | `diagram/flow_chart`　`chart/waterfall_chart` | 1 |
| 6–8 | 现状诊断 | 观测 vs 解释分离，每条诊断挂证据 | 两图并排 + 通栏第三面板 | 2–3 |
| 9 | 对比基准 | 用替代方案／同业／期间澄清决策 | `table/comparison_matrix`　`chart/grouped_bar_chart` | 1 |
| 10 | **建议与优先序** | 行动 + 为什么更优 + 预期效果 + 依赖 + 取舍 | `table/comparison_matrix`（含层级列） | 1 |
| 11 | 路线图 | 建议转为排序行动（阶段／输出／决策门） | `diagram/roadmap_chart`　`diagram/milestone_chart` | 1 |
| 12 | 风险与缓释 | 每条风险配触发证据、影响、缓释、责任人 | `table/metric_table` | 1 |
| 13 | **决策请求** | 要什么决策 + 不决策的后果 | `table/record_table`（ask/action/owner/consequence） | 1 |
| 14+ | 附录证据 | 审计与深挖所需的明细 | `table/hierarchical_table` | n |

**页面固定"外框"（chrome）**：左上 `动作标题（两行）+ 发丝线` → 其下 `单位／图表索引行` → 右上 `章节追踪器 + 草稿标记` → 左下 `编号脚注 + 来源行` → 右下 `页码`。**每页 5–7 个模块，一条网格；留白用来分隔模块，绝不用留白代替缺失的模块。**

## 4. 标题写法（动作标题）

| ✅ 动作标题 | ❌ 话题标题 |
|---|---|
| 建议优先投入 A 赛道，因其单客户价值是 B 的 2.4 倍 | 赛道对比 |
| 当前口径无法支撑考核，需先闭合三处差异 | 数据质量问题 |
| 若不决策，Q4 将超支 82.36 万元 | 预算情况 |

**动作标题两行结构**：第一行给结论，第二行给该结论的依据或范围限定。

## 5. 数据与证据表达

- **每个图表必须编号**（A／B／C）+ **实心编号徽标** + **粗体图表标题（说明它展示了什么）** + **单位行**。
- **直接标注数值**；把 `Δ 差值与倍数`作为伴读文字放在条尾／线尾；**省略网格线与数值坐标轴**（本风格不用它们）。
- 决策相关的那个变化**用强调色标注**；每个计算过程加脚注。
- 观测与解释分离；**绝不发明基准、同业、目标或趋势**。
- **脚注**：页码左下角编号脚注 + 其下来源行，脚注编号从标题、单位行、标签处引用；保留来源、期间、口径、测算基础；估计值／代理值／情景值／计算值必须标明。**未标注出处的陈述不得当作事实呈现。**

## 6. 中电金信落地（色、字、装饰）

**配色映射**（上游九角色 → 本模板）：

| 上游角色 | 上游默认 | 本管线取值 |
|---|---|---|
| Field 页面底 | `#FFFFFF` | `#FFFFFF`（不变，白底是硬规则） |
| Dominant 支配色 | `#051C2C` | **`#0C2864` 藏蓝**（标题／徽标／主序列／轴／封面底） |
| Accent 强调色 | `#2251FF` | **`#266DE7` 亮蓝**（每图的"点"：被强调的条、优先层级、被高亮数字） |
| Accent tint | `#8FB8FF` | **`#E4E6EA` 浅灰**（次序列／推论面板底） |
| Body 正文 | `#333333` | **`#0C2864`**（正文与关键信息；纯黑被铁律 10 禁止） |
| Muted 弱化 | `#7F7F7F` | **`#778495` 灰蓝** |
| Hairline 发丝线 | `#B7B7B7` | **`#778495`** |
| Grid 表格行线 | `#E3E3E3` | **`#E4E6EA`** |
| Surface 面板底 | `#F7F7F7` | **`#E4E6EA`** |
| Negative 负值 | `#B3261E` | **`#DF203C` 红**（仅小字／细边框／小红标） |

**字号**：上游给 `动作标题 24 / 正文与关键信息 14 / 图表标题 13 / 标注 11–12 / 脚注 10`。
**裁决：全文（含脚注与标注）字号不得低于 13px，且只用 spec_lock `## typography` 声明的角色值**（模板：`tests/fixtures/spec_lock.full.md`；仲裁规则见 `doc-writing-discipline.md §4`）。**密度不够时减少模块数（5 个而非 7 个），不缩字号。**

**装饰**：只有发丝线与实心编号徽标。推论面板 = 浅灰底 + **左侧细强调条**（用 `scripts/round_accent_strips.py` 生成贴边 path，保证与面板圆角一致）。**避免卡片、渐变、发光、装饰性图标、填充式标注框。**

**与"白卡蓝边"的取舍**：本风格页优先用"**发丝线分区 + 左侧强调条**"替代圆角卡片；若某页用了圆角卡片，则该页不再算严格 MBB 风格——**同一册内不要两种混着用**。

## 7. 与其他风格的分工

| 维度 | `mbb-consulting` | `consulting-decision` | `operating-review` |
|---|---|---|---|
| 密度 | 最高（桌面阅读） | 中 | 中高 |
| 标题 | 两行动作标题 | 断言式标题 | 断言式标题（含方向） |
| 页面外框 | 全套 chrome（脚注/追踪器/单位行） | 结论条 | 结论条 + 读数栏 |
| 典型用途 | 投标、决策请示 | 方案、复盘 | 月报、周期复盘 |

## 9. 交付前自查（7 条）

- [ ] 每页标题是动作标题（结论），不是话题
- [ ] 每页证据在答案的正下方或紧邻处，且空间上相连
- [ ] 事实／假设／推论／建议四者可区分
- [ ] 每页 5–7 个模块；没有用留白代替缺失模块
- [ ] 图表有编号徽标 + 粗体标题 + 单位行 + 直接标值；无网格线与数值轴
- [ ] 脚注与来源行齐全；未标注出处的陈述没有当作事实
- [ ] 全文（含脚注）字号 ≥13px；没有为塞内容缩字号
