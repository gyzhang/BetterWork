# 长文档 → 大册派工流水线（L2 手册）

> 适用：源内容**不在当前上下文**（整本书、长报告、几十页文档汇编），成片页数按 40 页以上计。
> `references/long-doc-deck.md §1` 是判据与入口，本文承载**模板全文与批次操作规程**——派工时照抄本文 §2/§3/§4 的模板填空，不要凭记忆重写。
> 规模实测（2026-09-29 至 09-30）：27.7 万字符书稿 → 7 份章节摘要（磁盘合计约 40 万字符）→ 79 页成片（72 张手写 SVG + 7 张纯模板版式页）→ 79 页演讲者备注。

## 1. 何时必须派工（三选一即触发）

| 判据 | 阈值 | 不满足时 |
|---|---|---|
| 源文本量 | ≥4 万字符，或源是多份文件的汇编 | 内容已知且小 → 按 `references/workflows/standard-deck.md §1` 直接规划 |
| 成图册数 | ≥40 页（或用户点名「全天课/系列课/白皮书浓缩」） | ≤20 页 → 主代理自写，不必派工 |
| 上下文 | 原文**读不进**当前上下文（读了就挤掉写页所需的规则上下文） | 能整篇读入 → 不必派工 |

**反例（不必派工，派了反而更慢）**：单月经营复盘 14 页、方案汇报 20 页——内容与数字都在一次会话里给全。
**为什么必须派工**：大册的失败模式不是画不好一页，而是**第 30 页忘了第 3 页的口径**、以及主代理把上下文喂给原文后写不动页。

## 2. Stage 1：`_digest/` 章节摘要（固定字段模板）

**切分**：一个并行子代理负责**一篇（或 3–5 章）**，文件名按来源结构落 `<project>/_digest/`（实测：`00-front-tail.md` / `p1.md`…`p5.md` / `appendix.md`）。
**派工指令必须写死三件事**：① 只准读点名的源文件（列出绝对路径）；② 逐字段照抄，不得改写「逐字」段；③ 不得引入源外事实。

每章按下列 10 段输出，段名与序号一并落盘（后续 Stage 2/3 要按段号回查）：

```markdown
# 第 N 章　<章标题>
## 1. 章节号与标题、小节清单        # 小节号 + 标题全列；章首题记逐字
## 2. 本章承诺 / 读完后你能回答 / 一句话讲明白 / 定义框（逐字）
## 3. 核心判断（逐字全文 + 小节号）   # 一条一段，标 (N.x)，页面上的结论只能从这里来
## 4. 全部数字（逐条）               # 见下方五字段
## 5. 论证骨架（每小节 2–3 句，保留关键措辞）
## 6. 书内表格                      # 原表逐行搬，保留表头与口径行
## 7. 配图                          # 图号 + 图内文字 + 源文件路径（重绘时要用）
## 8. 本章小结 / 行动清单 / 面向非专业读者的补充（逐字）
## 9. 金句候选（逐字 + 小节定位）
## 10. 边界/局限/撤回（原文自述，逐条）  # 作者自己画的外推边界，页面上不得越
```

**第 4 段的五字段（一条一行，`|` 分隔）**：

```
<数值/区间> | 口径：<这个数字测的是什么、分母是谁> | 时点：<数据快照或实验年份> | 来源：<机构/作者 + 标题 + 日期，原文给了 URL 才写 URL> | 证据级别：<原文自己的定性，如「非常弱的证据」/「特定场景经验」>
```

- 原文没给的信息**写「未在原文出现」占位，不要留空也不要补**——页面脚注直接继承这个诚实度。
- 「逐字」段（§2/§3/§8/§9/§10）是**口径的唯一载体**：转述会把「按比例折算」讲成「实测」，改一个字就丢出处。
- 主代理**不整份读 digest**（读得动也喂不进后续批次）。主代理只读：Stage 2 自己写的 `_plan.md` + 抽查式回查单个段号。

## 3. Stage 2：`_plan.md` 派工单（主代理独占，是全册唯一来源）

`_plan.md` 同时是**页面职责的唯一来源**与 **`pages.json` 的唯一来源**（Stage 5 直接由它生成，避免两套页序漂移）。三个块：

### 3.1 全局纪律（所有批次必须遵守，违反即返工）

10–12 条，逐条写「做/不做 + 判据」。**数值一律指向 L0，不在这里重抄**（见 `doc-writing-discipline.md §2` 纪律 1）：

- 必读三件：`templates/<公司>.md`（色板/字号/版式/坐标）、`svg-native-guide.md §2`（语法合同与分组）、`references/workflows/svg-authoring-and-quality-gates.md §2.4`（骨架三步转换）与 `references/workflows/svg-authoring-and-quality-gates.md §2.8`（分组与容器的隐性约束）
- 内容只准来自 `_digest/` 对应篇，必要时回读原文；**禁止自己编数字、禁止补 URL**；摘要写「未在原文出现」的页面也不许出现
- 标题写成**断言**（一句能独立读懂的判断），由模板版式占位符承载，**SVG 内绝不画页标题**（禁绘区与内容区坐标看 `档案 §6`）
- 色板与字号看 `spec_lock.md` 与 `档案 §2`/`档案 §4`；密度不够时**删模块，不缩字号**
- 分组强制、容器嵌套、bounds 留白：照 `references/workflows/svg-authoring-and-quality-gates.md §2.8` 三条原文执行
- 值驱动图形：几何用 `$PPTM_HOME/skills/ppt-master/scripts/svg_position_calculator.py` 算，禁止手算；两条注释与 `<g id="<key>-area">` 包裹照 `references/workflows/svg-authoring-and-quality-gates.md §2.5`
- 每页底部 `page-footnote` 组：出处（第 N 章 N.x）+ 口径 + 时点 + 来源（五字段直接来自摘要第 4 段）
- XML 注释内不得出现连续两个连字符；不用 `<style>`/class/animate/foreignObject/HTML 实体/emoji

### 3.2 自检方式（各批独立）

写本文 §5 的闸门隔离命令（机制与坑同节），**不要**让批次直接对共享工作区跑校验器。批次名在派工单里就为每批写死（如 `--batch b03`），不要留给批次代理自己取——脚本已强制 `--batch` 必填，但「各批不同名」只有主代理在派工单里能保。

### 3.3 页面清单（按批分组）

先在文件头定义骨架图例（实测六类够用，选不出图时「零图表」是合法结论）：
`A=结论条+卡片区｜B=KPI+图表｜C=发丝线表格｜D=阶梯/流程/循环拓扑｜E=左右对照｜F=参考卡（高密度清单）`

每页一条，格式固定：

```markdown
- **p23_155day-ledger** 〔B/C〕标题：「一笔可以核对到底的账：第 100 天冻结口径与 155 天全程口径，两套数字分开记」（6.1，核心判断 1）
  收：A 组与 B 组数字逐项带口径（摘要第 4 段）；「有门禁与门禁被满足是两个不同的命题」。
```

- `pNN_kebab-case-id`：NN 是**内容页序号**（不含纯版式页），kebab id 会被 Stage 5 用作 `pages.json` 与 `notes/` 的文件名主干
- 〔骨架〕= 版面选型，允许复合（`B/C`）；拓扑类看 `diagrams-library.md §2`，值/表类看 `charts-library.md §3`
- 标题必须是**断言**；括号里回指章号与「核心判断 N」，让读者能追溯到摘要段号
- 「收：」列 2–5 条内容项，每条都要能在摘要里定位到——定位不到就删这条页面职责
- 页数账：`全册 = 内容页数（写 SVG）+ 纯版式页数（封面/篇章页/封底，pages.json 里 src 为 null）`，两类页在清单里都要点名，防止 Stage 5 页序错位

## 4. Stage 3：分批写 SVG（子代理输入清单）

一个批次 = 8–14 页 = 一个并行子代理。批次之间**不共享待写页**，也不共享已写页的修改权。

**给每个批次代理的四项输入（缺一不可）**：
1. `_plan.md` 的全局纪律整块（原文贴进指令，不要让代理去猜）
2. 本批页面清单条目（含标题与「收：」）
3. 本批对应的 `_digest/` 文件路径（只给它这一篇）
4. **2–3 张标杆原型页**：主代理在派工前先手写三种不同骨架的定稿页（实测用 `p01`〔A〕、`p20`〔B〕、`p68`〔C〕），批次照抄其写法与密度基线

**批次代理的产出边界**：
- 只新增/改写**本批**的 `svg_output/pNN_*.svg`
- 不改 `spec_lock.md`、不改别人的页、不动 `_plan.md`（发现问题回报主代理，由主代理改派工单）
- 标题不写进 SVG（写进 `_plan.md`，Stage 5 由 `pages.json` 承载）

## 5. Stage 4：闸门隔离（本流程最大的坑，必须照做）

**根因**：`scripts/verify_palette.py`、`scripts/verify_layout.py`、`scripts/verify_geometry.py` 都是 `<project>/svg_output/*.svg` **全目录扫描**。并行派工时目录里同时躺着别人未完成的页——你跑校验，报的是别人的错（实测一批 9 页去验，报出数十条与本批无关的 error，批次会去"修"不属于自己的页）。

**隔离跑法（脚本已实装）**：唯一命令落点在本节，派工时把下面这条原样抄进批次指令，不要凭记忆重写：

```bash
env -u PYTHONPATH PPTM_HOME=/path/to/ppt-master python3 scripts/gatecheck.py <project_dir> --pages 'p15_*' 'p16_*' --batch B03
```
**`--batch` 已改为必填（2026-09-30）**：临时目录按批次名建，两批同名就是共用同一个 `/tmp/gatecheck_<同名>/`——先跑完的那批会把还在跑的那批的页清掉，而报告照样全绿（静默失效）。脚本不给默认值，漏传即 exit 2 拒跑；但脚本无法知道你是不是在并行，**各批名字必须不同**这条仍靠派工单保证。

机制：建 `/tmp/gatecheck_<批次名>/`，只拷 `spec_lock.md` + 你点名的页（**不拷别人的页**），串跑三闸门，打印每条 error 与该校验器自己的修法；退出码 0 = 本批全过。跑完默认删临时目录，排查时加 `--keep`。

**变异验证（2026-09-30，脚本落盘时实测）**：同一目录放一张越板色 + 侵入标题禁绘区的坏页 `p99`，
- 直跑 `verify_palette.py <dir>` / `verify_layout.py <dir>` → 判失败（复现互扰）
- `gatecheck.py --pages 'p02_*'` → 通过，且只报本批页名（隔离生效）
- `gatecheck.py --pages 'p99_*'` → 配色与版式两闸都 FAIL 并打印原修法
- 另用真实图表页改一根柱的高度不改 `chart-data` → 数据几何闸报 `status=mismatch`（守卫有牙齿）

前三条已于同日沉入回归：`tests/selftest_e2e.py --suite palette` 末尾的「批次隔离」五断言（互扰复现下的隔离阳性、本批输出不含别人的页名、点名坏页须失败、漏传 `--batch` 须 exit 2、页名模式打不中任何页须 exit 2）。数据几何那条已在 `geometry` 套里有同名断言（注入改高不改 `chart-data`）。

**收尾**：批次全绿后页归位到工作区 `svg_output/`，由主代理对**全册**跑一次 `references/workflows/delivery.md §3` 的 `svg_native_export.py`（三闸门已串在导出前），任一页未过即拒跑。

## 6. Stage 5：`pages.json`、merge、讲稿备注

- **`pages.json` 由 `_plan.md` 生成**，不另起一套页序：`src` 指向 `svg_output/` 的 **0-based 页序**，纯版式页写 `src: null`，`title` 逐字取 `_plan.md` 的断言标题，`tag` 取章号/篇章标签。字段契约见 `references/workflows/delivery.md §4`。
- 合入模板与交付校验照 `references/workflows/delivery.md §4` + `references/workflows/delivery.md §5`；大册另加两条断言：**页数 == `pages.json` 长度**、**标题占位符逐页非空**（7 张版式页最容易被漏）。
- **演讲者备注**（用户要讲稿时）：每页一个 `notes/<与 SVG 同名>.md`，五字段固定：

```
【时间】N 分钟
【一句话】<本页要立的那个判断，与 pages.json 标题同源>
【怎么讲】1) 起 2) 走 3) 收（模块顺序即视线顺序）
【提问】<一个可当场回答的动作/判断题>
【别踩】<本页最容易被讲错的口径>
```

  正文 130–200 字；引用页面原文时逐字，别把口径讲成绝对值。
- **上游导出与 merge 都不携带备注**，所以备注只在合并后的成片上注入一次：按 `pages.json` 的 `src` 映射把 `notes/` 对到最终册页序，`src: null` 的版式页另给一张备注表（封面/篇章页/封底各一条）。注入脚本按项目写（读 `pages.json` + `Presentation(...).slides[i].notes_slide.notes_text_frame`），技能侧只提供格式与断言；**交付断言：`pages_with_notes == 总页数`**（实测 79/79）。

## 7. 已实测的返工点（派工时写进批次指令，别等闸门抓）

| # | 返工点 | 防线 |
|---|---|---|
| 1 | 批次自己造数字、补 URL、把「按比例折算」写成「实测」 | 摘要第 4 段是数字唯一来源；「未在原文出现」不许被填上值；`SKILL.md` 铁律 7 |
| 2 | 断言标题写进 SVG → 撞标题禁绘区 | 标题只进 `_plan.md`/`pages.json`；`verify_layout.py` 的 L3 兜住 |
| 3 | 对共享工作区跑闸门，把别人的未完成页判成自己的错 | 本文 §5 的 `gatecheck.py` |
| 4 | 相邻页同骨架、批次间密度分化 | 标杆原型页 + 清单里预写骨架字母 |
| 5 | 备注超出配额或复述整页文字 | 五字段 + 130–200 字；【别踩】只写一处口径风险 |
| 6 | 旧配图数字被搬进新页（旧图自带图内标题与旧数字） | 一律按 `档案 §6` 坐标与 `spec_lock` 色板**重绘**，不搬旧图 |
