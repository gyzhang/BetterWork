# Renderer UI 任务入口

本文件只做阅读路由，不复制组件档位、几何数字、迁移清单或验收状态。设计与组件契约以 [docs/10-ui-ux-system.md](../../docs/10-ui-ux-system.md) 为唯一来源；工程与验证以 [docs/12-engineering-standards.md](../../docs/12-engineering-standards.md) 为唯一来源。发现冲突时先核对这两份文档和实际实现，同轮修复，不能自行按旧速查放宽规则。

| 本次工作 | 必读与执行入口 |
| --- | --- |
| 检查、Review 或创建页面 | docs/10 §10.1.1 的六步流程 → §10.1.2 真实导出台账 → §10.1.3 检查边界 |
| 页面名称与主要动作 | docs/10 §6.1；设置分区不是新增一级导航 |
| 页面骨架、滚动与版心 | docs/10 §8.3；设置内嵌形态查 PAGE_SHAPE_EXCEPTIONS |
| 间距、控件、排版、图标与表面 | docs/10 §9.8、§9.10、§9.13；读真实组件 props，不从历史评估复制数字 |
| 操作结果、对象状态与空态 | docs/10 §11.5.1、§11.5.2 和 §10.1 台账；同一结果一个出口 |
| 主题与成果画布 | docs/10 §9.3–§9.6；正式色系逐套检查完整契约 |
| 键盘、焦点、浮层与可访问名称 | docs/10 §10.1、§12；复用基座并验证实际行为 |
| Hook、IPC、请求过期保护与异常 | docs/12 §5、§8；视图只组合，动作在 hooks 收口 |
| 验证与例外 Review | docs/12 §1、§9、§10；npm run verify 含 ui:check，截图冒烟不替代本次页面走查 |

历史评估、日志与旧组件别名只用于理解决策；实现状态和开工授权查对应任务板。Review 报告写明页面/分支、复用关系、状态/反馈出口、验证证据及未验证项，不以“全绿”替代体验判断。
