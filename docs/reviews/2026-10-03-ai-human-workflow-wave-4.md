## 1. 第三方判断

协作链路已经能承担已授权的小型 UI 修复、回归测试、交接准备与推送后校验。本波不再只检查规则文件格式：实际启动 Codex CLI 与 Qoder 新会话，分别留下上下文、规则检索及操作证据；发现的焦点丢失和错误伪装为空态均已补回归。人类可以直接打开隔离合成窗口开始操作，减少自行造数和排查环境的负担。

完成度仍应分层判断。Codex CLI 可证明该次 AGENTS 指令进入上下文及相关文档被读取；Qoder 可证明该次规则检索和部分阅读、测试行为，无法证明完整原始注入。自动化覆盖的技术行为、AI 的走查与人类体验判定不能互相替代。安装态完整启动、VoiceOver、焦点环像素对比和真实模型语义仍待专项验证，原任务状态不因本波门禁通过而转为完成。

## 3. 产品修复与键盘证据

- 记忆捕获打开聚焦只读原文；自然 Tab 可到正文，Esc 取消不写库并归还触发按钮焦点。子菜单先消耗 Esc；中文输入组合及提交等待时不误关。原文、选区、范围与来源关系保持原契约。
- 专家新建、列表编辑和详情编辑聚焦名称；取消回到对应入口，保存成功回到详情“编辑配置”。参考加载、失败和真正空列表分开显示，失败使用局部 InlineError 与重试；重试不丢名称草稿或已选参考。
- Electron CDP 发送真实 Tab、Shift+Tab、Enter、Esc 和输入事件，检查专家参考菜单、精确参考保留、内联冲突条件保留及捕获关闭焦点。只有起始定位使用 focus；后续移动由浏览器键盘行为完成。读取焦点、outline 与几何不是焦点环像素或屏幕阅读器证明。
- `--probe-keyboard` 阻断 Tab，必须因“键盘焦点未到达”退出 1。旧生产代码上的捕获回归五项、专家初始焦点一项、参考错误一项均先红，修复后转绿；证据分别见 `/tmp/betterwork-wave-4-capture-before.log`、`expert-before.log`、`reference-before.log`（后两者同目录同前缀）。

默认 ui:check 保持 50 组：组件 16、四类页面各 8、真实 App/IPC/临时 SQLite 旅程一组、独立 SIGKILL/新 PID 恢复一组。应用旅程由 13 步增为 14 步，新增捕获键盘取消与零写入断言；页面组合追加专家参考加载失败重试和键盘路径、内联冲突键盘路径。不能用组数未变推断覆盖未增加，也不能把离线验收准备另算完整 UI 门禁成功。

## 4. AI 准备、人类操作的交接

`npm run ui:check -- --prepare-acceptance` 复用现有真实 App/Preload/IPC 和生产服务的部分装配，创建独立可见窗口、Chromium 用户目录及临时 SQLite。只使用虚构资料、确定性 Provider 与假的 Skill/依赖运行入口；禁止网络请求，不读取用户数据或实际模型配置。它没有走安装态完整 `main/index.ts`，不能代替签名安装或全部启动服务验收。

前置对象通过生产服务或类型化 IPC 准备并核对：回答来源记忆、用户口径、事实/经验、过期/未来规则、未解决冲突、八条优先规则、任务排除、成果 v1/v2、知识修订两版，以及成果来源专家 A 与当前 Task 专家 B 的区别。自动提炼关闭且无待运行作业。只有生产校验通过才写 `acceptance-preparation.json`；就绪文件为 `prepared-not-accepted`，不写人类结果。

关闭窗口保留合成库；指定原 `UI_RENDER_OUTPUT_DIR` 并加 `--reopen-acceptance` 可新进程重开。已有活动窗口拒绝重开，准备模式拒绝覆盖已有环境；合成库缺失时拒绝恢复，目录不能越过宿主输出范围。清理仅针对本次创建的进程组。`--acceptance-smoke` 核对合成挂起进入真实 Provider 请求、停止信号、failed/cancelled 终态、同库新 PID、15 条记忆/六个 Run 保留与重开零请求；这仍只证明准备链路。

人类在原清单 §1–§7 逐项操作并填写结果；§0 是前置准备，不代签验收。重复摘录、长正文、并发修订等各条验收所需的临时输入仍由 AI 按该条准备，不能仅凭预置对象就宣称所有操作已通过。真实模型 §8 需要独立的模型名称与整数预算授权，当前未调用。清单修正了超长单条造数建议及窗口最小宽度，新增键盘检查，所有原结果槽仍为待验。

## 5. 校验与剩余风险

完整验证曾因验收代码的变量遮蔽导致 typecheck 失败，已修正。新增冒烟首次在设置页查找“查看上下文”失败；先查 SQLite，四个既有 Run/Task 完整，再看宿主日志与截图，确认未切回工作页；修夹具导航后合成准备与新进程重开通过，没有扩大等待或放宽断言。键盘 Enter 事件补浏览器需要的文本字段后才真正打开菜单，不以 JS click 冒充键盘。

最终 verify、drift、测试计数及原始失败记录见[当日日志](../logs/2026-10-03.md)。提交后真实 pre-push 与当前 SHA 的 Actions 在最终交接核对。下一步优先收集本波原清单人工操作结果，并对“离开专家页时如何保留或提示草稿”做产品方案判定；不要继续用更多规则文件替代真实使用反馈。
