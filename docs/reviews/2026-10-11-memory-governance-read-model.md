现行 MemoryService.pendingGovernance 不随列表分页、检索或 workspace/expert 筛选缩小：输入是全域最新、存储状态 candidate/confirmed/expired 的完整集合，包含 rejected 候选、自然到期的 confirmed 和 legacy。其顺序为 updatedAt DESC/id ASC。本轮仅投影判定需要的身份、scope、normalizedHash、topicKey、有效期、status 和 candidateDisposition，不改输入集合、顺序或判据；不能把「当前全部生效」的旧注释误当成新加有效期过滤的授权。

冲突继续复用唯一策略的作用域/有效期交集及原始 topicKey/哈希规则，E7 左项优先次序与成对方向保持。治理批次中的两项已是最新修订，直接关联双方最新修订、一次读取精确裁决对身份后建调用内集合；不生成全域 ID 的 IN 参数，也不截断裁决集合。任一修订更新后旧裁决不能命中新对。完整裁决展示仍走既有 listConflictPairsForRevisionIds，保留共存说明、终态及历史读取口径，不将其改成另一套状态推导。

重复提示仍仅针对未拒绝的 candidate，查同规范 scope 与 normalizedHash 的第一条 confirmed，按原全域顺序取第一条；自然到期 confirmed 仍按存储状态参与，不新加来源或时间过滤。调用内按哈希组织 confirmed 集合，再复用原 scope/身份判定，不缓存、不改变写时抑制或幂等行为。

轻投影只用于提示判定，不能作为来源、依赖或正文证明；页内/详情/写回执的完整 MemoryRecord 校验、来源治理、召回门禁、投影重建和运行快照保持。无公共协议、算法版本、迁移、持久化索引、依赖或 UI 变化；不自动推进 WM/MI 人工验收。
