## 2. AI 应交付的证据

组件矩阵与页面矩阵分别报告；应用旅程标识为 `production-app-with-real-ipc-and-temporary-sqlite`。应用步骤为：工作空间就绪 → 一级导航 → 专家召唤只创建草稿 → 本期真实 Run → 回答来源捕获 → 自主工作口径设优先 → 本任务排除 → 恢复参与选择 → 从精确成果版本创建新任务 → 下期真实 Run → 合成请求失败 → 取消 → 销毁窗口、重开库并重装配服务后读取历史。

断言包括实际读取足迹、成果采用来源、两个独立 Task/Session/Run、精确版本不漂移、来源依赖保留、Provider 实际请求带入口径、失败/取消终态、源资料不变、无意外网络请求和无 Renderer 错误。持久化反例故意把恢复后的临时数据库改回排除状态，预期 CLI 退出 1；不能仅凭界面按钮变化通过。

应用旅程可用 `npm run ui:check -- --app-only` 定向复现；这一组通过不等于完整门禁。取消步骤等待实际 Provider 请求挂起后再点停止，并断言真实 AbortSignal 到达，避免只覆盖发送前取消。渲染宿主只等待有限动画过渡，持续 spinner 不阻塞截图；页面截图避开 toast/滚动条，设置分区按导航表面的主题 Token 核对，仍要求两帧稳定。

验证数字与命令退出码见[收口日志](../logs/2026-10-03.md)，最终 SHA/CI 随交接核对。截图逐步产出到当次 `UI_RENDER_OUTPUT_DIR`，CI 失败保留截图、完整/部分读数与合成旅程临时库/资料，成功保留 `results.json` 读数；不上传 Chromium 用户数据目录，不把本机临时截图当作永久云端证据。CLI 子进程探针不继承主矩阵输出目录，每次应用旅程新建数据库，复用输出目录也不继承历史 Run。
