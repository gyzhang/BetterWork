## 测试路径

1. 在 `/Users/kevin/temp/kevin1003` 创建工作空间。
2. 将仓库书稿章节复制到该工作空间的 `资料/` 子目录，经知识页重新导入，等待索引完成，并验证可检索。
3. 在隔离临时目录准备并导入文件夹 Skill；分别确认信任、启用和依赖状态，再创建专家并绑定该 Skill。
4. 召唤专家，选择精确的书稿修订及用途，确认任务上下文后开始真实模型 Run。
5. 验证 Skill/知识工具执行、正文读取、Run 终态、来源证据及材料快照；将回答保存为 Markdown Artifact 并检查输入关系。
6. 将一条用户明确给出的工作偏好保存并确认到 Expert×Workspace 范围。
7. 在同一工作空间创建独立新任务，验证记忆读取足迹和回答中的偏好复用；不选择书稿材料，确认该 Run 没有该书稿的检索/读取足迹。
