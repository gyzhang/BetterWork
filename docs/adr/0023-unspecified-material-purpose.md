# ADR-0023：材料“其他”用途与未指定来源关系

- 状态：Accepted（2026-09-15）。
- 日期：2026-09-15。
- 依据：[专家与任务材料设计](../designs/experts-and-task-materials.md)、[材料、快照与运行来源契约](../development/material-contracts.md)、[ADR-0014](0014-expert-context-and-material-binding.md)。
- 关系：细化材料用途与 ArtifactInputRelation，不改变材料选择、读取范围或专家绑定边界。

## 背景

材料用途是任务中的语义提示，不是文件类型。原有用途集合要求每份材料在规则、本期输入、历史对比、结构参考、模板和背景参考中择一；会议纪要、需求说明和暂时无法判断用途的附件被迫获得可能误导的语义标签。

## 决策

1. 增加 `other` 材料用途，界面显示为“其他”。它表示本次未指定上述专门用途，不表示系统应自由扩大材料使用范围。
2. `other` 与其他用途一样属于 `TaskMaterialSelection`，材料仍必须显式选入任务并通过原有范围、版本和可读性校验。
3. Run 材料清单将“其他”明确传给模型为“其他（未指定用途）”，模型不得仅凭标签将其当作数据、规则、历史版本或模板。
4. 成果输入关系增加 `other`，不把未指定用途伪装成 `background`；历史关系数据保持不变，通过应用库 v23 扩展 SQLite 检查约束。
5. 该用途不改变 ExpertRevision 常用参考的来源限制，也不让 Workspace 文件成为专家常用参考；专家、任务和 Run 的既有绑定边界保持不变。

## 结果与实施

- 共享协议、Composer、资料面板和运行材料清单支持 `other`。
- `artifact_input_relations` 迁移 v23 保留原有关系并允许新增 `other` 关系。
- 相关协议、迁移和界面测试覆盖解析、选择、数据库升级和关系写入。
