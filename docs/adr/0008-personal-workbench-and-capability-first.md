# ADR-0008：个人工作台与基础能力配置前置

- 状态：Accepted（仅限下述用户已确认的产品与职责决策）
- 日期：2026-09-08
- 关联：延续 ADR-0002 的成果优先与 ADR-0003 的内核边界；不替代 ADR-0004 的混合记忆架构。

## 背景

原路线图把研究报告作为第一条产品路径，将专家 CRUD 和 Skill 扩展安排在后期；README 同时将教学作为首要定位。用户通过「集团智能体场景落地」实例明确了实际工作需要：使用平台资料及网络信息形成场景方案、报告和公司模板 PPT，在长期工作目录中持续积累。

用户明确确认基础配置先行，且同一工作由一个专家调用多项 Skill 完成。配置基础与完整扩展生态需要分开安排。

## 决策

1. 产品定位仍为个人 AI 工作台，专注个人提效，先自用再供周边同事使用；当前不以企业管理、组织提效或市场化为目标。
2. 产品实际可用性优先于教学。教学经验在建设后总结，不以教学简化限制实际工作闭环。
3. 开发顺序为 Skill 管理与配置 → 专家管理与配置 → 研究到汇报完整路径。
4. 专家是配置化的 ReAct 智能体，组合人格、系统提示词、知识范围、工具及多项 Skill，持续承担同一任务；不引入多专家交接或多 Agent 作为该路径前提。
5. 长期工作目录承接 Workspace。用户无需预先建立完整知识库，也可从任务和材料开始；历史知识、协作积累和成果参与后续工作。
6. 首条路径有六个讨论节点：理解与计划、网络调研完成、报告大纲、报告完成、PPT 大纲、PPT 完成与修改。成果为持续协作对象，最终 PPT 可编辑并由用户人工调整。
7. 分发包含内置专家、Skill 和必要资源，用户配置模型、搜索等外部服务后即可使用。用户公司的私有材料与模板不属于默认分发资源。

## 影响与未决事项

- 原路线图未来阶段顺序由 docs/07 §0 替代；保留旧阶段作为实现进度与历史规划档案。
- 不变更现有代码、数据库和 IPC；Agent Core 继续不依赖 Electron、SQLite 或具体厂商 SDK。
- Skill 包格式、脚本/MCP 支持范围、内置内容编辑策略、配置快照、知识过滤、讨论节点恢复、Office Worker、记忆投影等是后续设计事项，不因本 ADR 被接受而自动成为已接受技术方案。
- 具体功能与验收建议见 [产品修订稿](../reviews/2026-09-08-product-scope.md)，其中 §3–§7 待审阅。

## 验证方向

后续 A/B 需验证配置保存与实际执行一致；C 需使用真实工作样本验收完整研究到汇报及再次复用积累的路径。本轮仅完成参考实现静态核对和文档修订，不宣称这些能力已实现。
