# ADR-0020：经营分析的确定性数值边界

- 状态：Accepted（E53，2026-09-14）
- 前置：[ADR-0014](0014-expert-context-and-material-binding.md)、[ADR-0018](0018-office-input-parsing-boundary.md)。

## 决策

1. 期间变化和预算偏差由 `analyze_business_metrics` 确定性工具计算。模型负责从已读取材料提取并映射指标，不能在提示词中自行心算、补齐缺失值或刷新表格公式。
2. 工具输入显式区分 `current`、`previous` 和 `budget`，保留原始数值、变化额和比例；零基数比例不输出伪造百分比，而是写入结构化 warning。缺少当前值直接失败。
3. 首个内置 Skill「经营分析方法」只提供口径核对、材料选择和工具调用约定；公司财务规则、期间定义、单位和预算来源必须通过 Task 材料进入，不硬编码到 Agent Core 或工具。
4. 输出仍是 Run 临时结果。报告/PPT 是否采用结论由用户通过讨论节点确认，不能因为工具计算成功就自动发布 Artifact 或业务系统写入。

## 验证边界

合成数值覆盖正负变化、零基数、预算偏差、缺失指标和取消。Skill 以内置资源分发，引用真实存在的确定性工具；真实财务规则与两期业务输入留 E55 桌面验收。
