# 协作方式说明

这是一份用于 BetterWork 操作手册的虚构演示材料，不包含真实业务数据。

## 试用目标

把分散的资料整理成可继续修改的工作成果，并保留所用材料的来源。

## 约定的工作方式

1. 每项持续工作使用一个工作空间，原始资料放在对应的本地目录。
2. 开始任务前说明目标、读者、材料范围和交付格式。
3. 先确认资料里已有的事实，再说明建议；没有依据的内容标记为待确认。
4. 重要交付保存为成果，再按需要导出到工作空间。

## 本次交付要求

写一份简短的使用建议，包含「目标」「操作顺序」「检查清单」三个小节。
只使用这份演示材料，不使用联网搜索、不运行脚本。
