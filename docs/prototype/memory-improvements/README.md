## 五步评审

1. **F1 / D1：保留来源。** 点击「记住这段经验」，先确认保存按钮禁用；在只读原文中选择包含「𠮷」的文字并确认，观察码点区间与摘录。重复文字按所选原文区间定位，不猜第一次出现位置。独立修改记忆正文，再模拟保存并展开记录，来源和依赖不因改写而消失。空选区、半代理对选区会被拒绝；可用「模拟半代理对选区」按钮观察拒绝结果。正文须非空且不超过 2000 码点，摘录不超过 500 码点；切换「来源记录缺失」不能保存，也不能改为自主口径。重开后编辑再取消，已有模拟保存次数不增加。原文样例超过 500 码点，全选后确认应被拒绝；重新选择短片段才可继续。
2. **F2 / D2：排除与恢复。** 将 M1「本任务排除」，切换为无词面命中后点击「重算预览」，确认它仍在独立排除列表。点击「恢复参与选择」，结果仍可能不相关而落选。切换「预览失败」也不影响管理排除。范围外行仅有「此项当前不可查看」和「移除此排除」，不显示正文或来源。过去运行的只读快照不随操作改变。
3. **F3 / D3：优先的边界。** 默认无词面命中、按相关性选择时落选；切换「优先带入」可模拟入选。分别勾选预算不足、来源失效，确认优先仍落选；两者同时勾选时先显示来源门禁。取消模拟条件可恢复预览。这里只演示一条符合资格的自主约束，不把优先当作全局范围、额外权限或模型遵从承诺。
4. **F4 / D4：有条件共存。** 打开裁决，分别展开左右来源；空适用条件时不能保留两条。填写 1–300 码点说明后模拟保存，关闭再重开，原说明仍显示。保存后的未提交编辑不会覆盖已保存说明。刷新不保留；仅绑定示例精确修订 A/r1 与 B/r2，不模拟跨修订继承裁决。
5. **F5 / D5：换期返回。** 修改工作要求和草稿专家，分别回看旧记录、查看本次材料、查看精确成果 v1，再返回原任务，确认草稿和专家未丢失。材料须明确勾选；可以把 v1 按历史对比或结构参考用途引用到当前任务，返回后仍标 v1、未读取，不跟随 v2 或 latest。历史明确为「此次不发送」，不是删除。所有跳转和引用都不创建 Run、不发消息。
