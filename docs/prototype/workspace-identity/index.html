低保真原型 · 待拍板 2026-09-28 提出。本轮只定「工作空间怎么建」与「任务在侧栏怎么组织」两件事的结构与语义：侧栏分组可展开收起、可切窄栏；对话框的文件夹／名称／图标／颜色联动可点。配色与几何沿用 docs/10 现有档位，不新造视觉。工作空间色是身份色，与四套色系（jade/ink/ocean/sand）是两个维度。

工作空间身份与侧栏任务分组

两个概念：Workspace ＝ 一个本地文件夹 ＋ 一个可选别名 ＋ 图标与颜色；Task ＝ 在该文件夹里做的一件事。侧栏从「一条不分组的最近任务」改为「工作空间分组 ＋ 组内任务」。

二、可交互原型

A · 侧栏：工作空间分组 ＋ 组内任务

算台

工作空间

规则：点空间行只展开／收起，不改当前工作空间、不打断运行中的任务；点任务行才打开该任务（必要时顺带把 Composer 的目录绑定切过去）。默认只展开当前空间，其余折叠，展开状态是界面偏好（localStorage，与侧栏折叠同一档）。任务行 meta 只显示相对时间，只有进行中／失败才补一枚微标——完成态不打标，侧栏回答的是「回到哪段工作」。

三、数据与契约

项 内容
迁移 workspaces 加 4 列：icon_id TEXT NOT NULL DEFAULT 'folder'、accent_id TEXT NOT NULL DEFAULT 'moss'、hidden_at INTEGER（NULL＝显示）、pinned_at INTEGER（本轮留空，不实现置顶）。 带 DEFAULT 即无需回填历史行；走 db/ 版本化迁移并补 db/migrate.test.ts 用例（docs/12 §6）。
协议 workspaceIconIdSchema／workspaceAccentIdSchema 用 z.enum 收在协议层，Main 与 Renderer 共用一份清单；workspaceSummarySchema 增这三项。枚举即白名单，不在 Repository 里再校验一遍。
通道 新增 workspace:create（rootPath＋别名＋图标＋色，路径已登记返回 workspace_path_taken 而不是静默复用）、workspace:update、workspace:set-hidden、workspace:list-groups（每空间前 20 条任务＋该空间任务总数，按空间最近活动排序）。三个注册 helper 之一承接，仍只出现在 register-ipc.ts。
Token appearance.ts 增 workspaceAccents 清单（id／中文名／明暗两值），styles.css 在明与暗两套 Variant 里各出一份 --ws-*。硬编码色值只允许出现在 Token 定义处（docs/12 §8）。图标 12 枚先进 icons.tsx（24 网格、currentColor、描边）再使用。
基座 需要登记进 docs/10 §10.1 台账的两件：图标与色板的单选选择器（对话框与「更改图标与颜色」共用一份，页面不得各画一套 .picker button）、侧栏工作空间分组（外壳用 NavList／NavItem 的既有几何，任务行仍用 RunSummaryRow，只新增「分组外壳＋chevron＋展示更多」这一层）。折叠窄栏只换 --nav-item-* 自定义属性，不重述几何。
不做 取色器、任意排序、拖拽移动分组、置顶、跨空间搜索任务、删除工作空间、按空间的独立知识索引。

五、拍板点（均附推荐）

D1 命名收口

推荐 A：Workspace 中文一律「工作空间」，中栏保留「任务工作区」；顺带改掉 Composer 触发器的「选择工作区」与对话框标题。 B＝沿用「工作区」，代价是侧栏标题与中栏同名。

D2 侧栏分组范围

推荐 A：所有工作空间并列（图 3 那种），侧栏列最近活跃的 8 个，其余收进「搜索全部工作空间」浮层。 B＝只显示当前空间的任务（改动最小，但持续项目仍然看不见）。

D3 身份属性

推荐 A：别名 ＋ 12 枚描边图标 ＋ 8 档成对色板。B＝只做别名（图标与颜色留到下一轮）。 C＝加任意颜色——不推荐，破坏对比度且违反 §9.2。

D4 不放「工作空间索引」开关

推荐 A：删。我们没有工作空间级索引这件事——知识是全局库＋集合，协议里写死了「集合仅个人分类，不代表工作空间授权」 （agent-protocol/src/index.ts:3096），检索范围由任务材料约束。放一个开关等于造一个没有真实语义的控件。 B＝把开关映射到已有的记忆自动提炼（workspace_memory_settings.auto_suggest_enabled，默认关闭且需同意条款）—— 真实，但它是带同意流程的设置，不适合塞进创建对话框。

D5 合并两颗按钮

推荐 A：去掉「打开本地文件夹」，只留「新建工作空间」，选目录是对话框第一步。 B＝保留两颗，但「打开本地文件夹」改为「选完目录后不填别名直接建」——仍是两颗做同一件事。

D6 空间行的点击语义

推荐 A：只展开／收起，绝不切换当前空间、绝不打断运行中的 Run；切换由任务行或 Composer 那一行承担。 B＝点空间行即切换当前空间（更快，但一次误点就把 Composer 的目录绑定换掉，与「动作不得破坏进行中的任务上下文」冲突）。

D7 隐藏而非删除

推荐 A：本轮菜单只有「从侧栏隐藏」，真删不进菜单（级联会带走整棵子树）。 B＝提供删除＋二次确认——需要新通道、新确认界面与迁移测试，建议单独一轮。

D8 任务行的状态呈现

推荐 A：meta 只显示相对时间，进行中／失败补一枚微标；实现方式是给 RunSummaryRow 加一个 compact 档（措辞仍只住在基座，不违反「状态 · 时间」护栏）。 B＝沿用「状态 · 时间」全文（零改动，但 25 个空间 × 每行一句状态在侧栏是噪声）。

D9 折叠窄栏

推荐 A：88px 下显示着色的空间图标（最多 6 枚＋「更多」），点图标＝展开侧栏并展开该空间。 B＝整组隐藏（现状把 .run-list 直接 display:none）。

D10 侧栏数据来源

推荐 A：新增 workspace:list-groups 一条分组查询（每空间 20 条＋总数）。 B＝复用现有两条通道在 Renderer 分组——零后端改动，但全局 100 条名额会被一个活跃空间吃满，「展示更多（k）」的 k 也拿不到。
