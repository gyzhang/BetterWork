三、拍板点（均附推荐）

D1 详情承载方式

推荐：同页详情态 + PageHeader 返回键（与成果页「列表 → 预览」一致，信任/配置/删除都在主区，窄屏不丢信息）。备选：右侧 Sheet（与模型编辑一致，但信任与删除属高风险动作，放浮层弱化其地位）；保留双栏（维持现状问题）。

D2 卡片状态密度

推荐：四 chip 全显（来源/信任/启用/环境，呼应 ADR-0011「不得用单一开关混同」）。备选：只显信任+启用（更安静，但环境未准备这一关键阻塞被藏进详情）。

D3 页头操作区组成

推荐：分段切换 + 导入主按钮一排，首版不做搜索（Skill 数量级为个位到几十，搜索是过早设计）。备选：加搜索框（与 WorkBuddy 顶部搜索同构，等数量上来再加）。

D4 模式偏好持久化

推荐：写入 localStorage，与侧栏折叠同机制，下次启动保持上次模式。备选：每次默认卡片（更简单，但重复操作成本回到用户身上）。
