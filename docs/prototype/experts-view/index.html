四、拍板点（均附推荐）

D1 「召唤」的位置与形态

推荐：卡片右上角绝对定位的小主按钮（28px 高、13px 字），整卡仍可点进配置。主行动待在最容易被看到的位置，同时不与整卡点击抢位。备选：右上角只放图标按钮（更安静，但「召唤」是这页唯一的主行动，图标不表意）；保持底部通栏（现状，卡片下半部被两枚按钮占满）。

D2 描述定高与提示的触发条件

推荐：固定三行高 ＋ 三行截断 ＋ 仅真溢出时挂 Tooltip（悬停 300ms 出现、键盘聚焦立即出现）。一行描述也占满三行，卡片高度因此恒定。备选：任何描述都可悬停（实现更简单，但短描述悬停出全文＝和没截断一样，读起来像坏掉）；点击卡片展开全文（多一次点击，且卡片高度会跳）。

D3 两页描述口径是否同轮统一

推荐：同轮把技能卡描述也改成三行定高 ＋ 同一套溢出提示。技能卡现在是两行钳制且一行会塌，与专家卡并排看就是一处不一致（§3.4 同一件事两种长相）。备选：本轮只改专家页，技能页留到下一轮（改动面小，但两页并排的不一致继续留在产品里）。

D4 列表模式的行内容

推荐：图标 ＋ 名称 ＋ 生命周期徽标 ＋ 描述单行省略 ＋ 能力与记忆计数 ＋「召唤／配置详情」，全部走 ListRow 现成槽位。选专家主要靠描述，所以描述留在行里。备选：不带描述（行更密，但两行才能看清一个专家，列表就失去意义）。

D5 内置专家的编辑入口

推荐：详情页主按钮按来源分档 —— 用户专家「编辑配置」，内置专家「复制为用户专家」，复制后直接进入编辑，与技能页 复制并编辑 同口径（ADR-0011：内置只读、用户副本可改）。备选：保持「编辑配置」可点，点击后内联提示「内置专家需先复制」（多一次失败往返，但按钮文案统一）。

D6 卡片底部按钮的措辞

推荐：改成「配置详情」。这枚按钮进的是详情页，详情页里才有编辑；「查看配置」听起来像只读，光哥本轮的疑问正来自这里。备选：保持「查看配置」；或改成「配置」并在内置专家卡片上显示「内置只读」徽标（徽标已按 D5 出现在详情页，卡片上再加是重复信息）。
