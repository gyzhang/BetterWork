# 品牌与视觉方向

## 1. 品牌名称

- 中文主品牌：算台
- 英文品牌：BetterWork
- 标准组合：算台 BetterWork
- 品类描述：知识工作者的个人 AI 工作台

## 2. 品牌解释

“算台”来自算盘和工作台：

- 算盘代表计算、秩序、积累和工具理性。
- 工作台代表持续工作、材料组织和成果生产。
- 智能节点代表知识检索、推理和创造。

## 3. 推荐文案

品牌主张：

> 以我所知，成我所作

品牌主张作为独立口号出现时，末尾不加句号；嵌入正文行文时按上下文使用标点。

产品定位：

> 算台是一款面向知识工作者的个人 AI 工作台。它理解并调用你的资料、记忆与工作方法，帮你完成研究、分析、文档与演示。

首页短文案：

> 让每一份积累，都参与下一次创造。

备选品牌主张：

- 把积累，变成成果。
- 知有所积，事有所成。
- 让知识为你工作。

“本地管理”和“自由连接模型”属于产品能力，不作为品牌主文案。可在功能说明中表达为：

> 资料与记忆由你管理，公网、内网与本地模型皆可连接。

## 4. 图标方向

标志从产品定位的现代含义出发——「知识工作者的工作台」，不绑定算盘意象：

- 圆角方形桌面应用轮廓
- 表达「知识与灵感在工作台上转化为成果」的核心叙事
- 避免机器人、脑、灯泡，以及「AI sparkle」「魔法棒」等功能俗套符号
- 避免与常见界面图标撞语义（头像、汉堡、加载点、载具、显示器、铅笔等）

推荐色彩：

- 墨蓝：专业、沉静、个人知识空间
- 暖铜：传统算盘、工具感
- 玉绿：知识激活、成长和洞察

正式图标要求：

- 先以概念图探索，再重绘为 SVG
- 保持 16/24/32/64 像素可识别
- 减少高光和细线
- 支持浅色、深色和单色版本
- 不在应用图标中放置中文或英文文字

### 4.1 标志（现行 v6）

标志主文件为 [`assets/betterwork-logo.svg`](assets/betterwork-logo.svg)。

构成语义（书上碰出火花）：

- 玉绿圆角方块：工作台的台面，也是桌面应用的圆角轮廓
- 翻开的书：知识与资料，「以我所知」
- 四芒星与两粒外溅火星：知识相击而生的灵感火花，「成我所作」；书是碰撞发生的台面
- 火花造型承自「墨滴落台」方向的血缘演化，延续「知识经台面转化为产出」的叙事
- 全部图形以镂空负形表达，实心色块保证小尺寸成立
- 双版本规则：标准版（含两粒外溅溅点）用于 64px 及以上场合（文档、README、应用图标），即主文件形态；简版（满版、去溅点，星与书放大占满版面）用于小于 64px 的应用内界面，侧栏品牌位 28px 起用

变体与使用规则：

- **背景必须透明**：标志文件不铺设任何底色，PNG 导出必须保留 alpha 通道
- 彩色版：台面玉绿（`#2F6B5D`），书与火花为镂空
- 单色版：台面取品牌色或近黑，镂空结构不变；应用内以 `currentColor` 渲染以适配色系
- 16 / 24 / 32 / 64 像素下必须可识别；最小使用尺寸 16px
- 等比缩放，不拉伸、不加底板、不加投影、不放任何文字
- 标志旁的文字标识使用「算台 BetterWork」字标，不与标志合并绘制

更迭记录：v1–v4 为算盘方向（细线框珠、横排胶囊、梁分上下加珠、加粗梁珠），v4 被指认似滑板车，据此放弃算盘意象；v5 负形「工」字/文本光标，被评过于抽象且有银行标志联想；随后横向探索数十个候选方向，光哥选定「墨滴落台」并指示改造为「书上灵感火花」；魔法棒替换案经渲染验证读作铅笔而否决，纯四芒星因撞「AI 功能按钮」俗套加两粒外溅火星改为「碰撞火花」，v6（现行）经 16/24/32/128 像素与深色底渲染自检后定稿；随后侧栏实装观感不佳，经 1:1 真实尺寸模拟对比，确认 24px 下四元素互相干扰，应用内改用 28px 满版去溅点简版，标准版（含溅点）保留于主文件用于大尺寸场合。

## 5. UI 气质

- 专业但不过度企业化
- 安静、清晰、克制
- 强调工作内容而不是 AI 装饰
- 进度可见，避免无意义加载动画
- Artifact、Evidence 和知识内容拥有更高视觉层级
- 中文排版优先，同时支持英文内容

界面视觉隐喻为“纸张、墨色、青玉”。青玉色承担激活和关键动作，品牌图形保持抽象简洁，不在界面中堆叠传统装饰。详细规范见 [UI/UX 体系与落地计划](10-ui-ux-system.md)。

青玉是默认品牌色系，不是唯一外观。算台从 UI Foundation 起支持浅色、深色与跟随系统，并提供青玉、纸墨、远洋、暖砂等成对色系；切换色系不改变产品品牌结构和 Artifact 自身配色。

## 6. 信息架构

长期主要入口：

```text
工作台
├── Tasks
├── Artifacts
├── Specialists
├── Knowledge
└── Capabilities
```

任务工作区采用可折叠三层结构：

```text
应用导航 | Task 主工作区 | 过程 / 资料 / 成果
```

右侧上下文面板按场景出现，可完全收起；原始运行事件不作为默认主界面内容。
