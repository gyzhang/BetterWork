## 06:37 UI 反馈修复：窗口标题栏与 SVG 图标体系（状态：完成）

- 背景：光哥晨间人工验收提出四项反馈：①红绿灯与品牌区拥挤；②双击标题栏无法最大化；③界面图标是 Unicode 字符不是 SVG，观感业余；④询问通知机制设计现状。
- 变更内容：
  - 窗口：macOS 增加 `trafficLightPosition {x:16, y:18}`；`.task-header` 与非工作视图顶部 24px 拖拽条设为 `-webkit-app-region: drag`（此前整个窗口没有任何拖拽区，连移动窗口都不行）；新增 `window:toggle-maximize` IPC（协议定义 + Zod + preload `chrome.toggleMaximize()`），双击标题栏遵循系统 `AppleActionOnDoubleClick` 偏好（缩放/最小化/无操作）；侧栏品牌区下移避开红绿灯。
  - 图标：新建 `renderer/src/icons.tsx`（14 个内联描边 SVG 组件，currentColor、24 网格），替换 App.tsx 全部字符图标（▣◇▤⚙◀✓＋‹›×↑⌄），grep 确认无残留；补对齐样式。品牌字标「算」与格式徽标（MD/PDF）保留文字形式。
  - `docs/10-ui-ux-system.md` §12 新增图标规范与 macOS 窗口交互规范两条底线。
- 关键决策：手写 SVG 图标集而非引第三方库（14 个图标规模不值得加依赖，与 LobsterAI 同思路）；双击行为读系统偏好而非硬编码最大化。
- 教训：交接时的「UI Foundation 已完成」不等于窗口基础交互（拖拽区）已覆盖；今后窗口层改动要实际拖一下、双击一下再交付。

## 06:49 SVG 图标规范下沉到规则层（状态：完成）

- 背景：光哥复核「图标必须 SVG」是否已成体系约束。核实结果：docs/10 §12 有（晨间已加），但 `.qoder/rules/betterwork-ui.md`（改 renderer 文件时自动加载的场景规则）没有，存在回退风险。
- 变更内容：`betterwork-ui.md` 补充强制条目——系统操作、导航、按钮等界面功能图标一律使用内联 SVG（图标集 `icons.tsx`，currentColor、24 网格），禁 Unicode 字符/emoji，新增图标先进图标集；品牌字标与 MD/PDF 徽标除外。AGENTS.md 不重复此条（宪法层靠任务路由到 docs/10）。
- 关键决策：规则分层各司其职——docs/10 是详细规范真相源，rules 文件是触发时的强制清单，两层对齐但不互相复制全文。
- 教训：新增设计规范时要同步检查是否需要下沉到规则层，只写 docs 会在日常改码时看不见。
- 测试证据：grep 回读确认新条目字面正确；纯文档变更，不涉及代码。
- 相关文件：`.qoder/rules/betterwork-ui.md`、`docs/10-ui-ux-system.md`、`docs/logs/2026-09-04.md`

## 06:53 标题栏改为贯穿窗口的连续拖拽区（状态：完成）

- 背景：光哥指出对「标题栏」的理解分歧——他（Windows 惯例）指贯穿窗口顶部的一整条，我此前只把中栏任务头当标题栏，左（导航区）右（产物面板）顶部拖不了。他的理解是对的。
- 变更内容：
  - 拖拽区贯穿三栏：侧栏整体可拖（所有按钮 no-drag，含红绿灯周围）、中栏任务头/顶部条（原有）、上下文面板头部与折叠态可拖。
  - 双击最大化统一走模块级 `handleTitlebarDoubleClick`，带交互元素守护；顺带修掉「双击标题栏里的按钮（模型芯片等）会冒泡触发最大化」的隐藏 bug。
  - 修正过程发现并修复一处作用域错误：处理器初版定义在 App 组件内而 ContextPanel 引用不到，已提升到模块级。
- 关键决策：不做覆盖整个窗口的固定 overlay 条（会拦截顶部按钮点击），而是让三栏各自的头部区域成为拖拽段，视觉与手感等效于贯穿横条。
- 教训：与用户讨论窗口层概念时先对齐「标题栏」的指代；Electron 无边框窗口的拖拽区规划要一开始就按全窗口思考，而不是按主工作区组件思考。
- 测试证据：typecheck、42 个测试、构建全绿；`git diff --check` 通过。拖拽手感需光哥人工验收。
- 人工验收：从侧栏空白处、红绿灯周围、右侧面板头部拖动窗口；双击三栏标题区最大化/还原；双击标题区里的按钮不再触发最大化。
- 相关文件：`apps/desktop/src/renderer/src/App.tsx`、`apps/desktop/src/renderer/src/styles.css`
