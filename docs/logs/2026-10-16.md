## 20:35 解释干净数据库中的内置修订

- 结论：干净数据库首次登记内置 Skill/Expert 时会各生成初始修订；相同资源重复启动会复用修订，检测到 Skill 内容或 Expert 配置变化才创建新修订。

- 对模型配置变更的核对：现有 ModelProfile 只保存最后更新时间，无法还原完整编辑历史；但数据库和代码证据不支持模型配置变更触发修订。

## 20:40 说明重启检查与 Skill 实质修订的区别

- 结论：启动会触发内置资源比对，但本身不会生成修订。纳入内容哈希的文件路径或字节发生变化才会改变 Skill 哈希并生成新修订。
- 哈希范围：按排序后的包内相对路径与文件字节计算 SHA-256；排除 `betterwork.skill.json`、`runtime/wheelhouse/` 和操作系统元数据。
- 限制：SQLite 仅保存哈希，旧版 Skill 资源当前无法从受跟踪 Git 历史恢复。
