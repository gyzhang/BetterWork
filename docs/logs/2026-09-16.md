# 2026-09-16 工作日志

## 15:17 工作区选择器改造（状态：完成）

- 背景：用户参照 WorkBuddy 的工作空间选择方式，要求改进 BetterWork 的工作区选择功能，支持历史工作区列表、搜索、新建工作区和打开本地文件夹
- 变更内容：
  - `packages/agent-protocol/src/index.ts`：新增 `ListWorkspaces` IPC channel 和 `workspace.listAll()` API
  - `apps/desktop/src/main/persistence/workspace-repository.ts`：新增 `listAll()` 方法，按 `updated_at DESC` 返回所有工作区
  - `apps/desktop/src/main/ipc/register-ipc.ts`：注册 `ListWorkspaces` channel handler
  - `apps/desktop/src/preload/index.ts`：暴露 `listAll()` 到 renderer
  - `apps/desktop/src/renderer/src/icons.tsx`：新增 `FolderIcon`
  - `apps/desktop/src/renderer/src/components/WorkspaceSelector.tsx`：新建工作区选择器组件，基于 `PopoverMenu` 实现下拉列表 + 搜索框 + 底部操作按钮
  - `apps/desktop/src/renderer/src/styles.css`：新增工作区选择器样式（`--surface-raised`、`--border`、`--selection`、`--focus-ring` 等语义 Token）
  - `apps/desktop/src/renderer/src/App.tsx`：用 `WorkspaceSelector` 替换原有的内联工作区选择 UI
  - `apps/desktop/src/renderer/src/App.test.tsx`：补充 `listAll` mock
- 关键决策：
  - 复用现有 `PopoverMenu` 组件作为下拉基座，避免重复造轮子
  - 工作区列表按 `updated_at DESC` 排序，最近使用的工作区排在前面
  - 选择历史工作区和打开本地文件夹共用 `selectDirectory` IPC，选择后刷新工作区列表
