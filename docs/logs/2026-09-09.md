- 关键决策：guardian 自包含（只用 `node:` 内置模块与 `import type`），因此测试态由 Node 直接执行同一份 TS 源文件、开发与打包态由 Electron 以 `ELECTRON_RUN_AS_NODE=1` 执行构建产物，一份源码两条路径，不出现第二套实现；控制通道与脚本 stdout 是两条物理管道，脚本文本永不被当作控制消息解析（用例里让脚本打印伪造的 cleanup 事件，执行不会被提前结束）；宿主兜底同样只按 `-pgid` 发信号并用 `ps` 独立核验，核验不出来就如实报 `cleanupCompleted=false`，不退化成「只杀父 PID 后宣布已取消」；正常结束也清残留后代，但脚本自身成功而残留清不掉时仍报 succeeded，只把残留写进执行日志与 `console.error`，不用清理问题掩盖真实执行结果；guardian 的 `protocol` 失败映射到共享协议的 `spawn` 阶段（`JobFailurePhase` 没有 protocol 值），原始 code 保留在结果里供诊断。
