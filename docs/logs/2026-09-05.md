## 18:52 修复侧栏收起态展开按钮错位（状态：完成）

- 背景：光哥截图反馈：侧栏收起后，「展开导航」按钮飘到红绿灯一行（附图标记 2 处），与窗口标题带拖拽区重叠，且按钮一半溢出 60px 窄栏压在分隔线上。
- 排查：纯布局缺陷，直接查 CSS。`.sidebar-collapsed .sidebar-collapse-button` 残留 `position:absolute;top:22px;left:42px` 魔法数字——top:22px 落进 `.sidebar-top-drag`（0–40px）拖拽带；left:42px + 24px 按钮宽 = 66px，超出 60px 栏宽溢出。另有一处重复的 `position:absolute;z-index:7` 收起态规则。
- 变更内容：收起态 `.brand` 增加 `flex-wrap:wrap;row-gap:10px`，按钮改 `position:static;margin:0` 回文档流——收起时品牌标单独一行、展开按钮在下方居中自成一行，随容器自适应，无魔法数字；删除两处绝对定位残留规则。展开态不受影响（按钮仍 `margin-left:auto` 靠右）。
- 关键决策：用文档流换行而非继续调绝对定位坐标——60px 栏内品牌标（32px）与按钮（24px）本就放不下一行，换行是唯一无冲突解；此前绝对定位是「先写死坐标后改布局」留下的死代码。
- 教训：容器从 240px 收窄到 60px 时，任何为宽态写的绝对定位坐标都会失效；收窄布局的规则要整体重审，不能只改可见属性。
- 测试证据：grep 确认收起态按钮规则仅剩 `position:static;margin:0`；typecheck、42 个测试、构建全绿；`git diff --check` 通过。HMR 已生效，收起/展开交互待光哥人工验收。
- 人工验收（留给光哥）：①收起后展开按钮位于品牌标正下方居中，不碰红绿灯、不溢出栏外；②展开后按钮仍在品牌行右缘；③收起态双击品牌区仍可最大化窗口。

## 19:08 收起栏重设计：88px 宽 + 按钮位置稳定（状态：完成，待验收）

- 背景：上一版「按钮换行到品牌标下方」被光哥否——常规交互是收起后按钮保持在展开态同一锚点（侧栏右上角），不该跳位；且 60px 窄栏连 macOS 红绿灯都装不下，绿灯溢出到主工作区。
- 变更内容：收起栏 60→88px（红绿灯横跨约 16–68px，留 20px 余量），绿灯完全落在栏内；收起态 `.brand` 改回单行 `justify-content:space-between`（品牌标居左、展开按钮居右），上下 padding 与展开态对齐（24/18），按钮垂直位置两态完全一致（y≈58）；上一版的 `flex-wrap/row-gap` 换行方案撤销。
- 关键决策：栏宽由红绿灯实际占位倒推（68px + 边距 = 88px），而不是先定宽度再凑合；切换按钮的收敛锚点是「侧栏右上角」，两态同位是通行软件（Notion、ChatGPT 类）的标准做法，光哥指认后对齐。
- 教训：收窄布局时先盘点窗口系统控件（红绿灯）的最小占位再定栏宽；「位置稳定的切换按钮」是折叠交互的默认预期，自创的换行方案违背直觉。
- 测试证据：grep 回读收起态两条规则逐字正确；typecheck、42 个测试、构建全绿；`git diff --check` 通过。HMR 已生效。
- 人工验收（留给光哥）：①收起后红绿灯完整落在侧栏内；②展开/收起按钮同锚点（右上角）切换方向箭头；③收起态 + 按钮、导航图标在 88px 栏内的观感是否协调，不协调再微调按钮尺寸。

## 19:26 收起态图标居中修正（状态：完成，待验收）

- 背景：光哥验收 88px 收起栏基本认可，唯一残留：新建任务按钮的「+」在方块内不居中（截图红框）。
- 排查：按钮内容是「图标 + gap + 隐藏文字」三段——文字用 `font-size:0` 隐藏，但 flex `gap:7px` 仍生效，匿名文字项与图标之间保留 7px，把可见图标整体向左推约 3.5px。工作/成果/知识导航图标与设置入口结构相同，同病只是不显眼。
- 变更内容：收起态按钮规则补 `gap:0`，隐藏文字项不再占位，图标精确居中；展开态 gap 不受影响。
- 教训：`font-size:0` 只把文字变零宽，不取消 flex gap——「隐藏文字 + 保留间距」是图标按钮居中问题的典型暗源，检查居中问题时要连同匿名 flex 项一起数。
- 测试证据：grep 确认规则仅一处且含 `gap:0`；typecheck、42 个测试、构建全绿；`git diff --check` 通过。HMR 已生效，居中效果待光哥人工验收。
- 人工验收（留给光哥）：收起态「+」与导航图标在方块内水平居中。
