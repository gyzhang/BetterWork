## 1. 背景、用户与目标

算台以知识工作者已有资料完成研究、分析、报告与演示。知识管理必须让资料可找到、可理解、可管理；知识使用必须让选定版本可被任务读取，并能回到具体来源。聊天提示词不能替代真实材料绑定，连接测试不能替代实际语义检索。

目标用户是用本机制度、方案、项目资料、经营表格和历史汇报完成持续工作的个人知识工作者。需求来源是光哥的产品要求与本轮静态代码核对，不是已完成的用户调研或线上统计。

| 目标 | 验收目标 | 观测方式 |
| --- | --- | --- |
| 选材真实进入任务 | 所有研究入口用例中，可见材料与运行固定修订完全一致 | 自动集成测试＋人工核对 |
| 可读、可追溯 | 正文分页连续；每个新知识来源能回到固定修订及返回范围 | 合成材料＋来源点击走查 |
| 嵌入配置产生实际价值 | 配置后的索引与查询均走所选嵌入模型；故障时关键词可用且不伪装语义成功 | 捕获替身请求＋另行授权的真实模型验收 |
| 管理不伤历史 | 更新、分类、移除、源文件丢失均不覆盖历史任务读到的内容 | 真实 SQLite 迁移与重启测试 |
| 基本可用性 | 批量操作有进度、取消、终态；无空转按钮，无越界读取 | 故障注入＋人工走查 |

完成期限以逐卡证据为准。“两天”是建议推进窗口，不是整批功能的工期保证。当前没有搜索效果、耗时或使用率基线；目标不写成已测结果。

## 3. 范围与优先级

### P0：必须构成基础闭环

- 知识页勾选资料，创建带固定修订材料的研究草稿；仍由用户发送。
- 任务只能搜索、读取本次运行明确选定的知识修订。
- 知识详情可预览提取文本；任务来源可定位返回的正文或摘要。
- 选中、搜索摘要、正文读取、成果声明采用分开展示。
- 嵌入模型用于真实文档索引和查询；无模型或故障时可用关键词检索。
- 索引有覆盖率、进度、取消、失败、重试和重启收口，切换模型不混用向量。

### P1：同一补齐计划，按独立任务推进

- 单层资料集合：创建、改名、删除、加入/移出、过滤；不移动本机文件。
- 来源状态检查：存在且一致、已变化、找不到、无法读取、尚未检查。
- XLSX/CSV/PPTX 知识导入：保留表格/行/幻灯片定位与必要解析警告。

### 明确后置，不作为 KM 完成条件

- 成果一键回收知识：本轮不新增入口；继续使用现有成果版本引用。未来设计需固定成果版本、记录派生链、防重复，并单独授权。
- OCR、扫描 PDF 识别、图片理解、HTML/网页收藏、自动目录监控、自动标签/摘要、知识图谱、Rerank、云同步、企业权限和全文物理擦除。
- 不给 Memory 加嵌入召回，不改变 WM 自动提炼范围；不做 Office 编辑器、公式引擎或新成果格式生成。

## 4. 用户旅程与功能规则

### 4.1 导入和维护资料（P0，Office 扩展 P1）

**故事**：作为知识工作者，我希望知道哪些资料已可用、哪些仍在处理，以便放心进入任务。

入口为知识页“导入资料”。选择本机文件后出现逐文件状态；解析成功即能关键词检索，语义索引另显状态。用户可取消剩余处理，已成功资料保留；作业结束后，失败、中断或取消的条目均可明确选取并手动重试，不重复处理成功项。取消不撤销已经完成的导入。

刷新原文件会形成新知识修订，旧任务仍固定原修订。重建搜索索引不等于刷新原文件。移除只从当前资料库与候选列表隐藏，不删除本机原件或历史修订；确认文案明确历史记录仍可回看。重新导入是新登记，不偷偷复活此前的集合成员。

异常至少覆盖：单文件解析失败但其他文件继续；取消或应用退出后没有永远“处理中”的记录；普通兼容重建失败保留旧索引，强制重建按 §4.5 先停用旧语义索引，两者均不损坏保存文本。

### 4.2 查找资料与建立研究草稿（P0）

**故事**：作为研究者，我希望把自己勾选的资料直接交给新任务，而不是只生成一句研究提示词。

知识页搜索可在全部资料或当前集合中执行；结果显示资料标题、定位、摘要及版本。同一资料命中多处不重复占用材料名额。搜索结果不等于选择，默认不勾选；用户可勾选本次已展示结果，清楚看到已选数量。

“用已选资料研究”仅在有选择时可用。动作创建新任务草稿，使用当前工作空间、通用助手，不继承旧任务的专家、Skill、模型专用选择或工具授权；把勾选时的知识版本和默认“背景”用途带到 Composer。用户可改用途、增删材料、修改问题，再主动发送。没有工作空间时使用既有工作空间选择流程，不偷偷建目录。

不得先清空当前任务再尝试保存新任务。当前任务运行中拒绝创建新研究且保留选择；已有未保存草稿时先用既有保存/离开确认交互，失败后仍留原任务。切换搜索/集合后清空结果勾选并给局部反馈，避免隐形跨查询选择。

异常至少覆盖：资料在点击前被移除，保留选择并标失效；创建失败或迟到响应不得把用户带离当前工作；超过材料上限时要求减少选择，不静默截断。

### 4.3 读取正文与回看来源（P0）

**故事**：作为任务协作者，我希望助手能读到选定资料的具体内容，并说明读了哪里，以便验证结论。

模型先得到材料清单；按需要搜索摘要或分段读取正文，不自动塞入全部资料。读取绑定运行开始时的知识修订。源文件后来变动或消失，不影响已保存修订的读取；界面说明“这是导入时的文本”，不冒称实时原文。

知识详情可浏览历史版本、提取文本和定位，标明提取范围与解析警告。此预览是用户查看，不写入 Run 读取足迹，也不表示模型看过。正文耗尽、被截断和尚有后页必须可区分。

任务资料面板默认当前 Run，历史 Run 需明确选择。搜索摘要与正文读取各有标签；点击来源只预览该次实际返回的固定修订区间，不把后续全文标成已读；如需浏览更多且资料仍在库，可另进资料详情。“打开本机原件”是另一个动作，不能替代版本预览。材料不在本 Run 范围、修订/哈希不符或游标失效时明确拒绝，绝不回退到最新或全库。

### 4.4 成果采用的可解释性（P0）

**故事**：作为成果审阅者，我希望分清任务曾接触的资料和成果声明使用的依据，以便检查而不是误信来源徽标。

任务资料区展示选材和访问记录；成果详情分别展示“声明采用的依据”和“本次运行访问过的资料”。模型或用户必须显式选择采用关系，不能仅因搜索命中、正文读取或材料用途而自动采用。

声明只证明“该成果声明使用了此来源”，不证明推理正确、逐句引用完整或人工批准。没有声明或明确清空来源均显示“未声明采用依据”，同时保留是否主动清空的事实；旧版本自动附带的来源显示“历史关联，未核实采用”，不追溯编造采用事实。人工修订继承已声明关系时标明继承，不冒称重新读取；历史未核实关系经连续编辑仍未核实，只有用户主动重新选取才能形成新声明。

异常至少覆盖：其他 Run 的来源不能被冒用；未知或未读材料的自动声明被拒绝；未声明来源的合法成果仍可保存。新流程不通过扫描正文中的路径或引用编号猜测声明。

### 4.5 语义查找与模型状态（P0）

**故事**：作为已配置嵌入模型的用户，我希望同义问题也能找到资料，同时知道搜索现在是否真的用了模型。

继续在现有模型设置管理嵌入模型；知识页展示当前使用的模型、语义索引覆盖与重建入口。已有模型配置不等于已建索引。首次启用语义检索时展示将处理的资料范围、模型和可能的调用费用，确认后建立索引；不反复泛化提醒“本地资料可能发给模型”。

开启后新导入资料纳入语义处理；关键词结果无需等待索引。知识页查询由提交动作触发，不因每次键入调用模型。任务检索使用同一服务，但只在选定修订内查找。模型切换/配置变化要显示需重建；不能混用旧模型文档向量与新模型查询向量。

普通重建只更新选定资料的兼容索引；“强制重建语义索引”用于同名模型已变化等情况，须单独确认：全部旧语义索引立即停用，重建当前资料，取消或部分失败也不恢复旧语义结果，关键词始终可用。历史任务资料不自动重建，需按需明确选择；界面不能把两种重建做成效果相同的按钮。

异常至少覆盖：没有可用模型或服务超时，保留关键词结果并显示降级原因；部分资料未索引，显示覆盖不完整；模型停用、取消或重启后不自动发起付费重试。

### 4.6 集合与来源检查（P1）

**故事**：作为长期积累资料的人，我希望按工作主题整理资料并检查原件，以便减少重复寻找。

集合是个人知识页的单层分类，同一资料可属于多个集合，不代表工作空间授权。默认“全部资料”和“未分类”是派生视图。删除集合只解除分类，移出集合不移出资料库；分类修改不更改内容版本，也不静默改变现有 Task 材料。

来源检查由用户手动发起，比较原路径当前文件与登记版本；检查不自动刷新、更改文件或调用模型。来源变化时提供“刷新内容”；原件缺失时仍可看保存文本和用于既有任务。

异常至少覆盖：重名集合或并发改名给当前表单错误；来源无权限和不存在分开展示；大型检查可取消，未检查项不标为正常。

### 4.7 Office 知识输入（P1）

**故事**：作为经营分析和汇报人员，我希望把工作簿、CSV 和演示资料作为长期知识检索，而不必每次另行转换。

XLSX 保留工作表、单元格地址、公式文本与缓存值，CSV 保留逻辑行，PPTX 保留实际演示顺序、文本、表格和备注。搜索和读取都回到同一提取修订。预览为提取文本，不承诺原版式或逐对象视觉还原。

异常至少覆盖：无缓存公式不能虚构结果；损坏、加密或超限文件明确失败；不支持的图表/图片内容提示范围；不运行宏、公式或外部连接。扫描 PDF 和只有图片的幻灯片不能伪装成已理解。

## 5. 文档线框与交互评审

沿用 UI/UX §8.3 页面骨架、已有布局组件、语义 Token、SVG 图标与反馈通道。知识页不显示任务上下文常驻右栏，不新增一级导航。本轮仅提供文档线框，不创建 HTML/TSX 原型；KM00 的评审门覆盖下列结构，若需可点击原型须另行授权。

```text
知识页
  统一页头：知识                         导入资料
  工具栏：集合筛选 | 搜索并提交 | 搜索方式与覆盖状态
  选择操作：已选数量 | 用已选资料研究 | 清除选择
  资料列表：勾选 | 标题/格式/版本 | 定位摘要 | 可用状态 | 更多
  作业区域（有任务才出现）：阶段、完成数、取消、结果详情

资料详情（主区子视图，可返回列表，保留搜索条件）
  标题、固定版本、原件状态、更新时间
  提取文本 / 版本列表 / 集合
  定位、分页、范围提示
  打开本机原件 | 检查来源 | 刷新内容 | 移出资料库

工作页资料面板
  当前 Run / 历史 Run
  本次选择的材料与用途
  访问记录：搜索摘要 / 正文读取 → 固定版本范围预览

成果详情
  声明采用的依据（模型声明 / 用户声明 / 继承）
  本次运行访问记录（不能冒称采用）
```

键盘可选择、取消、返回；窄窗口改用覆盖或主区切换，不压小字号。集合操作与当前对象错误使用既有局部反馈；导入/重建等跨页面结果进入通知中心，取消只更新对象状态，避免重复通知。

## 6. 验收标准

每项用 Given / When / Then 表达，技术边界用例详见契约和任务卡。

| 编号 | Given（前提） | When（动作） | Then（可观察结果） |
| --- | --- | --- | --- |
| K-01 | 四种已有格式的有效文件 | 导入 | 可搜索并预览固定修订，原件不变 |
| K-02 | 批次中有损坏文件 | 完成导入 | 成功与失败逐项可见，不整批假成功 |
| K-03 | 导入或重建中 | 取消并重启 | 已完成保留，剩余有终态，不自动重试 |
| K-04 | 两份资料、多处命中 | 勾选并研究 | 草稿恰有两份固定材料，尚未发送 |
| K-05 | 当前任务仍运行 | 点击研究 | 原任务和选择保留，明确拒绝 |
| K-06 | 点击前资料被移除或保存失败 | 创建研究 | 不创建可发送的半成品、不清空旧草稿 |
| K-07 | Run 已固定旧修订 | 原件更新后读取 | 返回旧文本和旧哈希，不跟随最新 |
| K-08 | 未选择的修订 | 模型直接读取 | 拒绝，无正文泄漏、无伪造足迹 |
| K-09 | 长文本含中文及增补字符 | 连续分页 | 内容连续无丢失，边界与剩余状态正确 |
| K-10 | 有搜索与读取记录 | 查看当前 Run 来源 | 两种行为分开，点击回到准确范围 |
| K-11 | 已读但未声明的来源 | 保存成果 | 不标为采用，仍可看运行访问记录 |
| K-12 | 来源属于其他 Run | 声明成果采用 | 拒绝越界声明，成果旧版本不变 |
| K-13 | 嵌入模型已配置、索引未建 | 启用并查询 | 索引/查询消费所选模型，显示真实覆盖 |
| K-14 | 模型不可用或向量未覆盖 | 搜索 | 关键词仍可用，明确降级，不假装语义命中 |
| K-15 | 重建时切换模型或取消 | 迟到响应到达 | 不发布旧配置索引、不污染当前结果 |
| K-16 | 一份资料属于两个集合 | 删除一个集合 | 资料与另一集合仍在，任务材料不变 |
| K-17 | 原文件被改写或移走 | 检查来源 | 状态准确，保存文本仍可看，不自动刷新 |
| K-18 | 集合名重复或检查无权限 | 提交操作 | 可行动错误/状态，不标成功 |
| K-19 | 有效 XLSX/CSV/PPTX | 导入、搜索、读取 | 地址/逻辑行/实际页序一致可追溯 |
| K-20 | 公式缺缓存或幻灯片仅图片 | 读取提取文本 | 明示未提取部分，不生成虚构值 |
| K-21 | Office 文件损坏、超限或处理中取消 | 导入 | 有明确终态，原件及已有修订无损 |

## 7. 非功能与观测

- 源文件只读；索引可重建，历史知识修订与任务证据不可当缓存清空。
- 管理、预览与索引不依赖聊天模型；自动测试使用合成材料、真实数据库及注入式网络替身。
- 耗时目标、资源上限和检索算法验收只在契约定义；真实模型效果与自动确定性测试分栏，不用替身成功声称业务效果通过。
- 不新增远程埋点。使用本地作业记录、检索诊断、读取足迹和成果声明记录观察：任务绑定成功/失败、已处理数、覆盖数、降级原因、耗时、取消/失败终态。
- 默认诊断不写完整正文、查询明文、向量或密钥；既有 Run 事件按原持久化规则保留。日志只加必要 ID、计数和安全原因。

## 8. 依赖、风险与后续

依赖材料修订与 Run 快照、既有模型/凭据、Office 解析和 Artifact 版本能力，不依赖未完成的远程 MCP、API 服务或 WM 人工验收。编码前重新核对这些能力的真实状态。

主要风险是双数据库误当单事务、旧索引与新模型混用、分页/中文长度错误、搜索摘要被当全文、自动来源被误读为采用，以及 Office 解析造成界面阻塞。对应机制和停止条件在 ADR 与契约中给出。

建议先交付“选中 → 草稿 → 读取 → 来源”垂直路径，再接嵌入与作业，最后完成分类和 Office 增量。两天后按证据复盘，不以日期驱动放宽正确性或把未完成项标为已交付。完整顺序与唯一状态见 [KM 任务板](../development/tasks-knowledge.md)。
