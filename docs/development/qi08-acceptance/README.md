# QI08 人工验收材料

状态：**待用户验收**。此材料包只准备入口和虚构样本，不记录用户结论。自动化结果见 QI07；自动化结果不能代替本清单中的人工判断。

所有金额、期间、指标和成果均为虚构内容。离线窗口使用确定性 Provider 替身，不连接真实模型或外部服务。预置的 Artifact A/B 用于检查导航、精确版本和编辑状态，不代表系统已经读取下列 CSV/XLSX 或计算过其内容。

## 打开离线验收窗口

在仓库根目录运行：

```sh
UI_RENDER_OUTPUT_DIR=/tmp/betterwork-qi08 npm run ui:check -- --prepare-acceptance
```

终端会打印输出目录和窗口 PID。窗口关闭后，可以用同一目录只重开已有合成库：

```sh
UI_RENDER_OUTPUT_DIR=/tmp/betterwork-qi08 npm run ui:check -- --reopen-acceptance
```

若该目录已有 `acceptance-ready.json`，不要再次准备覆盖；使用 `--reopen-acceptance`，或换一个新的临时目录。准备与重开都会写 `prepared-not-accepted`，不会写入人工验收结论。

输出目录下的 `acceptance-preparation.json` 列出临时数据库目录、两份预置成果的 ID/版本、合成材料文件名和 `humanResultsWritten: false`。两份 Office 文件复制到该数据库目录的 `workspace/` 子目录，可在工作页添加为材料。合成口径文件也在同一目录，并作为预置知识来源。
